03

대손금의 손금 산입 사유 (령 §19의2①)

#대손사유귀속시기조정유형비고
1 상법상 소멸시효 완성 외상매출금·미수금 사유 발생일 신고조정 상법상 시효: 상사채권 5년
2 어음법상 소멸시효 완성 어음 사유 발생일 신고조정 어음: 3년, 상환청구권: 1년·6개월
3 수표법상 소멸시효 완성 수표 사유 발생일 신고조정 수표: 6개월
4 민법상 소멸시효 완성 대여금·선급금 사유 발생일 신고조정 민사채권 10년
5 회생계획인가 결정 또는 법원 면책결정으로 회수불능 확정 사유 발생일 신고조정 채무자회생법 적용
5의2 서민금융생활법에 따른 채무조정 면책 확정 사유 발생일 신고조정 신용회복지원협약
6 민사집행법 §102에 따라 경매 취소된 압류채권 사유 발생일 신고조정 무잉여 취소
7 수출·해외용역 채권으로 무역보험법상 회수불능 확인 사유 발생일 신고조정 한국무역보험공사 확인
8 채무자의 파산·강제집행·형의 집행·사업폐지·사망·실종·행방불명으로 회수불능 손비 계상일 결산조정 임의계상 사유
9 부도발생일로부터 6개월 이상 경과한 수표·어음·외상매출금
(중소기업 외상매출금: 부도 전 것만 해당)		 손비 계상일 결산조정 저당권 설정 시 제외
손금한도: 채권액 − 1,000원
9의2 중소기업 외상매출금·미수금으로 회수기일이 2년 이상 경과 손비 계상일 결산조정 특수관계인 거래 제외
10 재판상 화해 등 확정판결과 동일 효력으로 회수불능 확정 손비 계상일 결산조정
11 회수기일 6개월 이상 경과, 채권가액 30만원 이하 소액채권 손비 계상일 결산조정 채무자별 합계 기준
12·13 금융감독원 승인·요구 대손처리, 벤처투자회사 창업자 채권 손비 계상일 결산조정 금융회사·벤처투자회사 한정
⚡ 귀속시기 구분 — 핵심 암기
사유발생일 귀속 (1~7호)
소멸시효 완성, 회생계획인가, 면책결정,
경매취소, 무역보험 확인
→ 신고조정, 장부계상 불요
손비계상일 귀속 (8~13호)
파산·부도 6개월·소액채권 등
→ 결산조정, 반드시 장부에 계상해야 손금 인정
🚨 부도 6개월 특이사항 (9호) — 필독
  • 부도발생일 = 지급기일 (지급기일 전 부도확인 시 그 확인일)
  • 손금 산입 한도 = 채권가액 − 1,000원 (1원이 아님!)
  • 저당권을 설정하고 있는 경우 제외 → 저당권 있으면 대손처리 불가
  • 일반법인 어음·수표 → 가능 / 중소기업 외상매출금 → 부도 전 것만 가능

① 대손금 발생 시 세무조정 패턴
상황장부처리세무조정소득처분
대손금 ≤ 충당금 잔액 충당금과 상계 (충당금↓) 유보 감소
(충당금 손금불산입 유보 해소)		 유보
대손금 > 충당금 잔액 충당금 전액 상계 후
초과분 대손금(비용)계상		 충당금 부분: 유보 해소
초과분: 손금 인정 (조정 없음)		 —
충당금 없이 직접 대손처리 대손금(비용)으로 계상 조정 없음 (그대로 손금) —
대손 불인정 사유인데 계상 대손금(비용) 계상 손금불산입 (유보) △유보
법인세법 제34조 제3항 대손금이 발생한 경우 그 대손금을 대손충당금과 먼저 상계하여야 하고, 상계하고 남은 대손충당금은 다음 사업연도의 익금에 산입한다.
② 대손금 회수 시
법인세법 제19조의2 제3항 손금에 산입한 대손금 중 회수한 금액 → 회수한 날이 속하는 사업연도의 익금에 산입
  • 이미 손금산입된 대손금을 나중에 받으면 → 무조건 익금산입
  • 충당금과 상계 후 남은 충당금 잔액을 회수한 것도 익금 처리
③ 채권 재조정에 따른 현재가치 할인 (령 §19의2⑤)
시행령 제19조의2 제5항 기업회계기준에 따른 채권 재조정으로 장부가액과 현재가치의 차액을 대손금으로 계상한 경우 → 손금산입, 이후 기업회계기준의 환입방법에 따라 익금산입
05

대손충당금 한도 계산 방법

법인세법 시행령 제61조 제2항 한도 = 채권잔액 × MAX(1%, 대손실적률)
(금융회사의 경우: 금융위원회 적립기준, 1%, 대손실적률 중 큰 금액)
// ① 채권잔액 채권잔액 = 사업연도종료일 현재 외상매출금 + 대여금 + 그 밖에 준하는 채권의 장부가액 합계 // ② 대손실적률 (령 §61③) 대손실적률 = 직전 사업연도의 대손금 / 직전 사업연도 종료일의 채권잔액 (즉, 직전 연도 대손 발생 비율) // ③ 한도액 한도액 = 채권잔액 × MAX(1%, 대손실적률) // ④ 세무조정 계상액 ≤ 한도 → 조정 없음 (전액 손금) 계상액 ＞ 한도 → 손금불산입 (유보) 초과분
⚡ 채권잔액 계산 시 주의사항
  • 채권잔액 = 장부가액 (이미 대손충당금이 차감된 순액이 아닌 총액 기준)
  • 제외 채권: ① 구상채권 관련 대손충당금은 별도 (§61④)
    ② 손금불산입 채권(특수관계자 가지급금, 채무보증 구상채권)
  • 대손실적률 = 직전 연도 기준 → 당기 기준이 아님!
📊 일반법인 vs 금융회사 한도 비교
구분한도 기준
일반법인채권잔액 × MAX(1%, 대손실적률) 중 큰 금액
금융회사 (은행·보험·증권 등)금융위원회 적립기준 금액, 채권잔액×1%, 채권잔액×대손실적률 중 가장 큰 금액

07

합병·분할 시 대손충당금 승계

법인세법 제34조 제4항 합병·분할 시 대손충당금 중 합병법인등이 승계받은 금액
→ 해당 대손충당금에 대응하는 채권이 함께 승계되는 경우만 해당
→ 합병법인등이 합병(분할)등기일에 보유하는 대손충당금으로 간주

08

구상채권상각충당금 (법 §35 / 령 §63)

① 개요
법인세법 제35조 제1항 법률에 따라 신용보증사업을 하는 내국법인 중 대통령령으로 정하는 법인이 구상채권상각충당금을 손비로 계상한 경우 → 한도 내 손금산입
  • 신용보증기금, 기술보증기금, 농림수산업자신용보증기금
  • 한국무역보험공사, 지역신용보증재단, 신용보증재단중앙회
  • 한국주택금융공사, 서민금융진흥원
  • 엔지니어링·소프트웨어·건설·전기공사 등 각종 공제조합 등
② 한도 계산 (령 §63③) — 대손충당금과 비교
// 대손충당금 한도 (일반법인) 대손충당금 한도 = 채권잔액 × MAX(1%, 대손실적률) → 1%와 실적률 중 "큰" 값 // 구상채권상각충당금 한도 구상채권충당금 한도 = 신용보증잔액 × MIN(1%, 구상채권발생률) → 1%와 발생률 중 "작은" 값
🚨 MAX vs MIN 함정 — 반드시 암기!
대손충당금
채권잔액 × MAX(1%, 대손실적률)
→ 더 큰 값으로 한도 설정
구상채권상각충당금
신용보증잔액 × MIN(1%, 구상채권발생률)
→ 더 작은 값으로 한도 설정
③ 사용·환입 처리 (법 §35③)
  • 구상채권 대손 발생 시 → 충당금과 먼저 상계
  • 상계 후 남은 충당금 잔액 → 다음 사업연도 익금산입
  • 처리 구조는 대손충당금과 동일
④ IFRS 적용 법인 특례 (법 §35②)
법인세법 제35조 제2항 한국채택국제회계기준(K-IFRS) 적용 법인 중 대통령령으로 정하는 법인이 구상채권상각충당금을 세무조정계산서에 계상하고, 이익처분 시 구상채권상각충당금으로 적립한 경우 → 결산 시 손비로 계상한 것으로 간주

※ IFRS는 충당금 설정 방식이 달라 세무조정계산서+이익처분 적립으로 결산조정 요건을 갈음함

09

계산 예제

예제 1 — 대손충당금 한도 계산 및 세무조정
📋 문제
(주)세무의 당기말 채권잔액: 500,000,000원
전기 채권잔액: 400,000,000원 / 전기 대손금 발생액: 3,200,000원
당기 대손충당금 계상액: 8,000,000원
// Step 1. 대손실적률 계산 대손실적률 = 3,200,000 ÷ 400,000,000 = 0.8% // Step 2. 한도액 MAX(1%, 0.8%) = 1% 한도액 = 500,000,000 × 1% = 5,000,000원 // Step 3. 세무조정 계상액 = 8,000,000원 한도초과 = 8,000,000 - 5,000,000 = 3,000,000원 → 손금불산입 (△유보) 3,000,000원
예제 2 — 대손충당금 전체 사이클 세무조정
📋 문제
전기말 대손충당금 장부잔액: 6,000,000원 (세무상 유보: 2,000,000원)
당기 대손금 발생 및 충당금 상계: 4,000,000원
당기말 충당금 설정 한도: 5,000,000원 / 계상액: 7,000,000원
// Step 1. 기초 충당금 익금환입 처리 장부상 환입 = 6,000,000원 (전액 익금환입, 법 §34③) 익금불산입 = 2,000,000원 (세무상 유보 잔액 한도) 익금산입 = 6,000,000 - 2,000,000 = 4,000,000원 (기타) // Step 2. 대손금 충당금 상계 대손금 4,000,000원 → 충당금 상계 (별도 조정 없음, 유보 이미 소멸) // Step 3. 당기 충당금 신규 설정 한도초과 = 7,000,000 - 5,000,000 = 2,000,000원 → 손금불산입 (△유보) 2,000,000원
예제 3 — 구상채권상각충당금 한도 계산
📋 문제
신용보증잔액: 100억원
전기 신용보증잔액: 80억원 / 당기 발생 구상채권: 6,400만원
// 구상채권발생률 구상채권발생률 = 64,000,000 ÷ 8,000,000,000 = 0.8% // 한도액 = MIN(1%, 0.8%) MIN(1%, 0.8%) = 0.8% 한도액 = 10,000,000,000 × 0.8% = 80,000,000원 ※ 대손충당금이었다면 MAX → 1% → 1억원이었을 것!

출제 포인트 & 오답 함정 총정리

🎯 1차 최빈출 포인트 15선
  • 대손충당금은 결산조정 / 대손금은 신고조정(원칙) — 항상 구분
  • 대손충당금 한도 = 채권잔액 × MAX(1%, 대손실적률)
  • 구상채권상각충당금 한도 = 신용보증잔액 × MIN(1%, 구상채권발생률)
  • 대손실적률 기준: 직전 사업연도 채권잔액과 대손금
  • 충당금 잔액은 무조건 다음연도 전액 익금산입 (법 §34③)
  • 대손금 발생 시 충당금에서 먼저 상계 (법 §34③)
  • 부도 6개월 손금한도 = 채권액 − 1,000원
  • 부도 6개월 시 저당권 설정이 있으면 대손 불가
  • 중소기업 2년 이상 미회수 → 특수관계인 제외
  • 소액채권 기준: 채권가액 30만원 이하 (채무자별 합계)
  • 채무보증 구상채권 → 대손처리 원칙 불가 (예외 6가지)
  • 특수관계인 가지급금 → 대손처리 절대 불가
  • 대손충당금 합병 승계 → 채권도 함께 승계되어야만 인정
  • 퇴직급여충당금 합병 승계 → 채권 동반 요건 없음
  • 대손금 회수 시 → 회수일이 속하는 사업연도 익금산입
⚠ 자주 나오는 오답 함정 비교

"대손실적률은 당기 발생 대손금으로 계산" 오답 — 직전 사업연도 기준
"구상채권상각충당금 한도는 MAX(1%, 발생률)" 오답 — MIN(1%, 구상채권발생률)
"부도어음 대손금은 채권 전액 손금산입 가능" 오답 — 채권액 − 1,000원
"채무보증 구상채권은 모두 대손처리 불가" 오답 — 법정 허용 채무보증(공정거래법, 금융회사, 신용보증법인 등) 제외
