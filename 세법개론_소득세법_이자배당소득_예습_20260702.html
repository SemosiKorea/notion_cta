1. 이자소득 (§16)

1-1. 이자소득의 범위 (§16①)

💡 쉬운 비유: 이자소득은 "돈을 빌려줘서 받는 이자"예요. 은행 예금이자, 채권이자, 직접 돈을 빌려주고 받는 이자(비영업대금이익)까지 모두 포함됩니다.

2. 배당소득 (§17)

2-1. 배당소득의 범위 (§17①)

💡 쉬운 비유: 배당소득은 "회사의 주주로서 받는 수익"이에요. 실제 현금배당 외에도 자본전입으로 받은 무상주, 합병·해산 시 초과분 등도 세법은 배당으로 봅니다 — 이것이 의제배당이에요!

2-4. 배당소득금액 계산 & Gross-up (§17③) 🔴 계산형 핵심

§17③ 배당소득금액 = 총수입금액 (원칙)
단, 아래 Gross-up 적용 배당소득 → 총수입금액 + 10% (=배당소득금액)

✓ Gross-up 적용 대상 (§17③단서)

  • §17①1호 (내국법인 배당·분배금)
  • §17①2호 (법인으로 보는 단체 배당)
  • §17①2의2호 (법인과세신탁 배당)
  • §17①3호 의제배당 (단, 제외 사유 없는 것)
  • §17①4호 (법인세법 처분 배당)
  • §17①5호 (집합투자기구) 중 일부

✕ Gross-up 제외 (§17③1~7호)

  • 1호: 자본감소 의제배당 중 법인세 미과세분
  • 2호: 자기주식소각이익 자본전입 (2년 이내) 의제배당
  • 3호: 토지재평가차액 자본전입 의제배당
  • 4호: §17②5호 (자기주식보유 지분율 증가) 의제배당
  • 5호: 최저한세 비과세·면제·감면 법인 배당
  • 6호: 재평가적립금 위반 감액 배당
  • 7호: 법인세법§18⑧나·다목 자본준비금 감액 배당
🚨 출자공동사업자 배당소득(§17①8호) → Gross-up 제외!
§17③은 1·2·2의2·3·4·5호에만 적용. 8호(출자공동사업자)는 Gross-up 대상이 아님

3-3. 금융소득 2,000만원 기준 — 종합과세 판단 (§14③6호·§14④)

§14③6호 — 분리과세 이자·배당소득 이자소득+배당소득 합계 ≤ 2,000만원이면서 원천징수된 소득 → 종합과세 합산 제외
단, 출자공동사업자 배당소득(§17①8호)은 제외 (무조건 종합과세)
🚨 §14④ — 2,000만원 기준액 계산 시 Gross-up 제외!
배당소득에는 §17③단서에 따라 더하는 금액(Gross-up 10%)을 포함하지 아니한다
→ 기준액 계산: 이자소득 + 배당소득(Gross-up 제외) 합계를 2,000만원과 비교

3-5. 배당세액공제 (§56) — Gross-up 이중과세 조정

§56① 종합소득에 Gross-up 배당소득금액이 합산된 경우
→ Gross-up 금액 = 배당세액공제액으로 산출세액에서 공제
§56④ 배당세액공제 대상 종합소득과세표준에 포함된 배당소득금액으로서 이자소득등의 종합과세기준금액(2,000만원)을 초과하는 것
✅ 배당세액공제 = Gross-up 금액(배당수령액 × 10%) = 이중과세(법인세+소득세) 조정 장치

3-6. 종합 계산 예제 — 2023년 59번 기출 유사형

📐 종합과세 배당소득금액 계산

ㄱ. 비상장내국법인 금전배당: 15,000,000원
ㄴ. 법인세법 처분 배당: 4,000,000원
ㄷ. 자기주식소각이익 자본전입 의제배당 (소각일~전입 2년 이내): 8,000,000원
ㄹ. 외국법인 배당: 3,000,000원
ㅁ. 감자 의제배당: 6,000,000원
ㅂ. 출자공동사업자 배당소득: 2,000,000원
ㅅ. 주식포괄적교환차익 자본준비금 전입 무상주: 1,000,000원
(이자소득 별도 10,000,000원)
① 배당소득 판별 ㄱ·ㄴ·ㄷ·ㄹ·ㅁ·ㅂ = 배당소득 ✓ / ㅅ = 자본준비금 전입 → 비과세 ✗ (§17②2)
② 총수입금액 합계 15M+4M+8M+3M+6M+2M = 38,000,000원
③ 종합과세 기준금액 판단 (Gross-up 제외) 이자 10M + 배당 38M = 48M > 2,000만원 → 종합과세 (§14④)
④ Gross-up 적용 대상 판별 ㄱ(15M)·ㄴ(4M)·ㄹ(3M)·ㅁ(6M) = 28M → Gross-up ✓
ㄷ(자기주식 2년이내): Gross-up 제외(§17③2호)
ㅂ(출자공동사업자): Gross-up 제외 (§17①8호)
⑤ Gross-up 금액 28,000,000 × 10% = 2,800,000원 (§17③단서)
종합과세 배당소득금액 = 38,000,000 + 2,800,000 = 40,800,000원

⚠️ 오답 함정 — 기출 기반 10선

❌
"금융소득 2,000만원 기준 계산 시 Gross-up 금액을 포함한다"

→ 정답: §14④ — 배당소득 합계액에 Gross-up 금액을 포함하지 않는다. 수령 원금 기준으로 2,000만원 비교

❌
"자기주식 소각이익 자본전입 무상주는 소각일과 관계없이 의제배당이다"

→ 정답: 소각일로부터 2년 이내 자본전입 시만 의제배당. 2년 초과 전입은 자본준비금으로 비과세 (§17③2호 참조)

❌
"출자공동사업자 배당소득도 Gross-up 대상이다"

→ 정답: §17③은 1·2·2의2·3·4·5호에 적용. 8호(출자공동사업자)는 Gross-up 제외

❌
"저축성보험은 모두 이자소득이다"

→ 정답: 10년 이상 유지 보험 및 종신형 연금보험의 보험차익은 이자소득 제외 (비과세). 10년 미만이면 이자소득 (§16①9)

❌
"비영업대금의 이익 원천징수세율은 14%이다"

→ 정답: 비영업대금의 이익 원천징수율은 25%. 일반 이자 14%와 다름 (§16①11)

❌
"출자공동사업자 배당소득은 2,000만원 이하이면 분리과세된다"

→ 정답: §14③6호에서 §17①8호(출자공동사업자)는 제외. 금액과 관계없이 종합과세 대상

❌
"집합투자기구 이익에서 채권 매매차익은 제외된다"

→ 정답: 제외되는 것은 상장내국법인 주식 매매차익만. 채권 매매차익은 포함 (§17①5)

❌
"잉여금처분 배당의 수입시기는 결산확정일이다"

→ 정답: 잉여금처분 배당 수입시기 = 잉여금 처분결의일. 결산확정일은 법인세법 처분 배당의 수입시기 (령§46①2, §46①6)

❌
"주식발행초과금을 자본전입한 무상주는 의제배당이다"

→ 정답: 상법§459① 자본준비금(주식발행초과금 등) 자본전입 → 의제배당 제외 (비과세) (§17②2가목)

❌
"통지예금 이자 수입시기는 이자 지급일이다"

→ 정답: 통지예금 이자 수입시기 = 인출일 (령§45⑤)
