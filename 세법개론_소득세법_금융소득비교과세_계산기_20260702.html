💰 금융소득 종합과세 비교과세 계산기

근거: 소득세법 제62조 (이자소득등의 종합과세 시 세액 계산 특례) | 2026.04.21 시행
원천징수세율: 소득세법 제129조 / 기본세율: 소득세법 제55조 | 2천만원 기준: 소득세법 제14조③6호

🔥 최빈출 포인트 (이자·배당소득 — 기출 19회, 매년 출제)

  1. 비교과세 = Max(①방법, ②방법) ★★★★★ — 두 계산 중 큰 금액이 최종 산출세액 (소법§62)
  2. 2천만원 초과 판단 시 Gross-up 금액 제외 ★★★★ — 원금 기준으로만 2천만원 비교 (소법§14④)
  3. ①방법: (금융소득 − 2천만원 + 타소득) 기본세율 + 2천만원×14% ★★★★ — (소법§62①1호)
  4. ②방법: 금융소득×14%(또는 25%) + 타소득 기본세율 ★★★★ — 분리과세 가정 비교 (소법§62①2호)
  5. 비영업대금이익 25%, 출자공동사업자 배당 25% ★★★ — 금융소득 내 세율 차이 (소법§129①)
  6. 출자공동사업자 배당 = 이자소득등 제외 ★★★ — §62 본문 후단: 이자소득등으로 보지 않음
  7. Gross-up 대상 배당 → 배당소득금액에만 포함, 2천만원 판단엔 미포함 ★★★

💡 핵심 개념 — 초등학생도 이해하는 비교과세

💡 쉬운 비유 — "2가지 계산서 중 더 비싼 것으로 내기"
은행이자·배당이 2천만원을 넘으면 나라에서 말합니다:
"① 번 계산서(종합과세 방식)로 계산해봐, ② 번 계산서(분리과세 방식으로 그냥 14% 때리기)로도 계산해봐.
둘 중에 더 비싼 걸로 내!" — 이게 바로 비교과세입니다.
왜냐고요? 금융소득이 너무 적으면 종합합산이 오히려 세금을 줄여주는 경우가 생기거든요. 그걸 막으려는 거예요.
📖 소득세법 제62조 (2026.04.21 시행)
거주자의 종합소득과세표준에 포함된 이자소득과 배당소득(이하 "이자소득등")이 종합과세기준금액(2천만원)을 초과하는 경우 → 종합소득 산출세액 = 다음 ①·② 중 큰 금액
※ 제17조①8호 출자공동사업자 배당 → 이자소득등으로 보지 않음 (별도 처리)
① 종합과세 방식 (소법§62①1호)
가. [금융소득 중 2천만원 초과분 + 타종합소득금액]
   → 기본세율 적용 산출세액

나. 2천만원 × 14%

= 가 + 나
② 분리과세 비교 방식 (소법§62①2호)
가. 금융소득 전체 × 원천징수세율
   (이자·배당 14%, 비영업대금 25%)

나. 타종합소득금액 → 기본세율 산출세액

= 가 + 나
⚠️ 2천만원 이하인 경우: §62①2호(분리과세 방식)만 적용 → 금융소득 14% + 타소득 기본세율

      📝 기출 예제 풀이 — 2023년 제60회 57번 (계산형)

      은행예금이자 3천만원 / 비실명이자 400만원 / 비영업대금이익 1,200만원 / 외국법인 배당 500만원 / 사업소득금액 4천만원 / 종합소득공제 900만원
      기본세율 일부: ≤1,400만원→6% / 1,400~5,000만원→84만원+초과분×15% / 5,000~8,800만원→624만원+초과분×24%
      • ①
        비실명이자: 분리과세 42% → 종합과세기준금액 판단에서 제외 이자소득등 = 3천+1,200+500 = 4,700만원 (2천만원 초과 → 비교과세) 비실명이자 §129②2호 45% → §14③3호 분리과세
      • ②
        ①방법: (4,700만원 − 2,000만원 + 4,000만원 − 900만원) × 기본세율 + 2,000만원×14% 과세표준 5,800만원 → 산출세액: 624만원+(5,800−5,000)만원×24% = 624+192 = 816만원 / 2,000×14% = 280만원 → 합계 1,096만원 소법§62①1호
      • ③
        ②방법: 금융소득 4,700만원×14% + 비영업대금이익은 이미 14% 적용 + 사업소득 기본세율 이자소득 3,000×14%=420 / 비영업대금 1,200×25%=300 / 외국법인 배당 500×14%=70 → 소계 790만원 / 사업소득 과세표준(4,000−900)=3,100만원 → 84+(3,100−1,400)×15%=84+255=339만원 → 합계 1,129만원 소법§62①2호
      • ④
        Max(①1,096만, ②1,129만) = 최종 산출세액 ✅ 11,290,000원 (정답 ②) 소법§62①

      ⚖️ ① 방법 vs ② 방법 핵심 비교

      항목① 종합과세 방식② 분리과세 비교 방식
      금융소득 처리 2천만원 초과분만 기본세율 합산
      2천만원은 14% 단순 적용      		 전액을 원천징수세율(14%·25%)로 계산
      타소득 처리 금융소득 초과분과 합산 후 기본세율 금융소득과 분리하여 별도 기본세율
      유리한 경우 타소득이 낮아 낮은 세율 구간에 걸릴 때 금융소득이 방대하거나 타소득이 높아 세율 구간이 높을 때
      비영업대금 효과 초과분에 기본세율 → 낮을 수 있음 25% 단일 적용 → ①보다 커질 수 있음
      Gross-up 반영 배당소득금액에 Gross-up 포함(+10%) 동일하게 배당소득금액 기준 계산

      ⚠️ 오답 함정 — 시험에서 자주 틀리는 포인트

      ❌
      "2천만원 기준 판단 시 Gross-up 금액을 포함한다"

      → 오답! 소득세법 §14④ 명시: 종합과세기준금액(2천만원) 판단 시 Gross-up(§17③ 단서 가산금)은 포함하지 않습니다. 원금 기준으로만 비교합니다.

      ❌
      "출자공동사업자 배당소득도 이자소득등에 포함하여 비교과세 계산한다"

      → 오답! §62 본문 후단: 제17조①8호 출자공동사업자 배당은 이자소득등으로 보지 않습니다. 타소득으로 분류해 ②방법 나목 처리 대상입니다.

      ❌
      "비영업대금이익은 항상 14%를 적용한다"

      → 오답! §129①1호나목: 비영업대금이익 원천징수세율은 25%입니다. 단, 온라인투자연계금융업자를 통해 받는 이자소득은 예외적으로 14%입니다.

      ❌
      "①방법이 항상 ②방법보다 크다(또는 작다)"

      → 오답! 어느 쪽이 클지는 금융소득 구성(비영업대금 비중)과 타소득 크기에 따라 달라집니다. 반드시 두 방법을 모두 계산하고 Max를 취해야 합니다.

      ❌
      "2천만원 이하 금융소득은 아무런 세금이 없다"

      → 오답! 분리과세로 원천징수(14%)로 납세의무가 종결됩니다. 종합과세 미합산이지, 세금이 없는 게 아닙니다.

      ❌
      "비교과세에서 ②방법의 타소득 계산 시 금융소득 공제액도 차감한다"

      → 오답! ②방법은 금융소득을 완전히 분리한 상태로 계산합니다. 타소득 과세표준 = 타종합소득금액 − 종합소득공제 (금융소득 포함 여부 무관하게 동일 공제 적용).
