# 세무사 시험 학습 프로젝트 지침

## 1. 프로젝트 목표

이 프로젝트의 1차 목표는 2027년도 세무사 제1차 시험 합격에 필요한 지식을 체계적으로 반복하는 것이다.

학습자료를 많이 만드는 것 자체를 목표로 하지 않는다. 모든 자료는 실제 시험문제의 정답률과 풀이속도를 높이는 데 사용되어야 한다.

## 2. 자료의 우선순위

자료가 서로 다를 때에는 다음 순서로 신뢰한다.

1. 국가법령정보센터의 시험 기준일 현재 법률·시행령·시행규칙
2. 큐넷의 시험 공고·출제범위·공식 정답
3. 실제 세무사 시험 원문
4. 최신 기본서와 객관식 문제집
5. 프로젝트에서 만든 기출분석 DB와 HTML 자료
6. AI가 자체적으로 생성한 설명과 예상문제

프로젝트가 만든 자료는 공식 원문을 대신할 수 없으며, 공식 원문과 대조한 뒤 사용한다.

## 3. 설명 방식

모든 개념은 먼저 초등학생도 이해할 수 있는 쉬운 말로 설명한다.

그다음 시험에서 사용하는 정확한 용어, 법적 요건, 공식과 예외를 제시한다.

쉬운 설명 때문에 법령이나 회계기준의 뜻이 달라지지 않도록 한다.

## 4. 세법자료 작성 원칙

세법자료는 다음 순서로 확인한다.

법률 → 시행령 → 시행규칙 → 별표·서식 → 관련 법률 → 판례·예규

각 자료에는 다음 사항을 표시한다.

* 법령 기준일
* 적용되는 귀속연도
* 개정 여부
* 근거 조문
* 일반원칙
* 예외
* 시험에서 자주 바꾸어 출제하는 표현
* O/X 문제와 해설
* 계산문제 또는 사례문제

법령 해석상 다툼이 있으면 판례·통설과 소수설을 구분한다.

확인되지 않은 내용은 사실처럼 작성하지 않고 ‘검증 필요’라고 표시한다.

## 5. 회계학자료 작성 원칙

회계학자료는 설명만으로 끝내지 않는다.

각 주제마다 다음을 포함한다.

1. 쉬운 개념 설명
2. 시험용 정의와 공식
3. 기본 예제
4. 직접 풀어보는 계산문제
5. 자주 하는 실수
6. 기출 변형문제
7. 제한시간
8. 오답 원인 기록
9. 24시간·7일·30일 뒤 재풀이 문제

계산과정에서 단위, 기간, 월할계산, 현재가치, 세후금액 및 반올림 방법을 명확하게 표시한다.

## 6. 기출분석 원칙

모든 기출문제에는 다음 정보를 부여한다.

* 시험연도
* 과목
* 문제번호
* 대단원
* 세부주제
* 계산형·이론형 구분
* 공식 정답
* 원문대조 여부
* 정답확인 여부
* 관련 조문 또는 회계기준
* 최초 정답 여부
* 풀이시간
* 오답 원인
* 최종 복습일

출제빈도는 원문대조가 끝난 문제만을 대상으로 계산한다.

AI가 분류한 빈도표만으로 중요도를 결정하지 않는다.

## 7. 복습 원칙

새로운 내용을 학습한 날에 기본문제를 푼다.

다음 일정으로 다시 확인한다.

* 24시간 후
* 7일 후
* 30일 후
* 시험 전 최종 회독

복습할 때 자료를 다시 읽기 전에 먼저 문제를 풀거나 내용을 떠올린다.

## 8. 파일 관리 원칙

파일명은 다음 형식으로 통일한다.

과목_대단원_세부주제_자료유형_기준일.html

예시:

회계학개론_재무회계_재고자산_계산훈련_20260702.html

각 파일 상단에는 다음 정보를 표시한다.

* 작성일
* 법령 또는 기준서 기준일
* 참고한 기출연도
* 검수상태
* 최종 수정일

## 9. 학습시간 보호 원칙

학습자료를 만드는 시간은 전체 공부시간의 20%를 넘기지 않는 것을 원칙으로 한다.

나머지 시간은 강의수강, 직접 계산, 객관식 문제풀이, 오답 복습에 사용한다.

예쁘게 꾸미는 작업보다 정답률과 풀이속도 개선을 우선한다.

## 10. 답변 및 자료 생성 시 금지사항

* 존재하지 않는 조문·판례·기출문제를 만들어내지 않는다.
* 개정 전 규정을 현재 규정처럼 설명하지 않는다.
* 확인되지 않은 출제빈도를 사실로 단정하지 않는다.
* 회계 계산과정을 생략한 채 정답만 제시하지 않는다.
* 사용자가 이해했다는 전제만으로 복습을 생략하지 않는다.
* 한 번의 회독을 과목 완성으로 평가하지 않는다.
