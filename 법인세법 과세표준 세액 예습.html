이월결손금 (법 §13①1 · §14③)

요건내용
발생 시기각 사업연도 개시일 전 15년 이내 개시 사업연도에서 발생
신고·결정 요건§60 신고 또는 §66 결정·경정 또는 국기법 §45 수정신고 과세표준에 포함된 결손금
공제 한도각 사업연도 소득의 80% (중소기업·회생기업 100%)
이월 가능 여부이월 가능 (비과세·소득공제와 다름)
공제 순서먼저 발생한 사업연도 결손금부터
⚡ 발생 연도별 이월공제 기간 변천 (시험 자주 출제)
결손금 발생 시기이월공제 가능 기간
2008년 이전 개시 사업연도5년
2009~2019년 개시 사업연도10년
2020년 이후 개시 사업연도15년
🚨 80% 한도 — 계산 주의
이월결손금이 각 사업연도 소득의 80%를 초과하는 경우 80%만 공제
공제받지 못한 잔액은 다음 연도로 계속 이월 (소멸하지 않음)

재해손실세액공제 (법 §58)

법인세법 제58조 제1항 (2026.01.02 시행) 천재지변 등 재해로 자산총액의 20% 이상 상실하여 납세 곤란한 경우
→ 공제 대상 세액 × (상실 자산 가액 / 상실 전 자산총액)을 세액에서 공제
// 재해손실세액공제액 계산 공제액 = 대상 세액 × (상실자산가액 / 상실 전 자산총액) // 한도: 상실자산가액 // 자산총액에 토지 가액은 포함하지 않음! // 공제 대상 세액 (법 §58①1·2) 1호: 재해 발생일 현재 부과 안 된 or 부과됐으나 미납된 법인세 2호: 재해 발생일이 속하는 사업연도 소득에 대한 법인세
구분내용
적용 요건자산총액의 20% 이상 상실
자산총액 범위토지 제외한 자산총액
신청 방법납세지 관할 세무서장에게 신청 (법 §58②)
이월공제없음
최저한세비적용
🚨 오답 함정
  • "자산총액의 20% 이상" → 20% 미만이면 재해손실세액공제 불가
  • 토지는 자산총액 계산에서 제외 — 건물·기계장치 등만 포함
  • 세무서장에게 신청 해야 함 (임의 공제 불가)
09

사실과 다른 회계처리 경정에 따른 세액공제 (법 §58의3)

법인세법 제58조의3 제1항 사실과 다른 회계처리(분식회계)로 과세표준·세액 과다 계상 → 경정청구 후 경정을 받은 경우
→ 과다 납부세액을 환급 않고 경정일 속하는 사업연도부터 매년 20% 한도로 법인세에서 공제
항목내용
공제 방법환급 대신 이월하여 연간 20% 한도로 공제
요건 ①사업보고서·감사보고서에 수익·자산 과다계상 또는 손비·부채 과소계상
요건 ②법인·감사인·공인회계사가 경고·주의 등의 조치를 받을 것
합병·분할 시남은 세액 합병법인등이 승계하여 계속 공제
청산 해산 시청산소득 법인세 차감 후 즉시 환급
⚡ 수정신고와의 관계 (법 §58의3②)
경정일 이전 사업연도에 수정신고 납부세액이 있는 경우
→ 수정신고 납부세액에서 먼저 20% 한도로 차감

② 최저한세 구조
// 최저한세 검토 감면 후 세액 = 산출세액 − 세액감면 − 세액공제 최저한세액 = 과세표준(감면 전) × 최저한세율 IF 감면 후 세액 ≥ 최저한세액: 전액 감면 적용 IF 감면 후 세액 < 최저한세액: 미달분 만큼 감면 배제 → 배제되는 감면: 세액공제 먼저 배제 → 그 다음 소득공제·손금산입

  • 외국납부세액공제 (법인세법상)
  • 재해손실세액공제

🚨 최저한세로 배제된 세액공제 — 이월공제 가능!
최저한세 적용으로 배제된 세액공제액은 10년 이월공제 가능
But 최저한세로 배제된 소득공제액은 이월 불가 (법 §13②2)

기납부세액 (중간예납 · 원천징수 · 수시부과)

① 중간예납 (법 §63~§63의2)
법인세법 제63조 제1항 사업연도가 6개월 초과하는 내국법인 → 중간예납 의무
예외: 합병·분할에 의하지 않고 새로 설립된 법인의 최초 사업연도, 학교법인 등
// 방법 1: 직전연도 산출세액 기준 (§63의2①1) 중간예납세액 = (A − B − C − D) × 6/E A = 직전연도 확정 산출세액(가산세 포함, 토지양도소득 제외) B = 직전연도 감면 법인세액 C = 직전연도 원천징수세액 D = 직전연도 수시부과세액 E = 직전 사업연도 개월 수 // 방법 2: 중간예납기간 실적 기준 (§63의2①2) 중간예납세액 = (A − B − C − D) A = 중간예납기간을 1사업연도로 보고 계산한 법인세액 B~D = 해당 기간 감면·원천징수·수시부과
구분내용
납부기한중간예납기간 종료 후 2개월 이내
분납 가능중간예납세액 1천만원 초과 시
직전 산출세액 0인 경우→ 실적 기준(방법 2) 강제
공시대상기업집단 소속법인→ 실적 기준(방법 2) 강제

② 원천징수세액

  • 법인세 신고 시 기납부세액으로 공제
  • 원천징수세액 초과 시 환급

  • 확정신고 시 기납부세액으로 공제

계산 예제

예제 1 — 과세표준 및 산출세액
📋 문제
(주)세무 (일반 내국법인, 12월 결산)
각 사업연도 소득금액: 15억원 / 이월결손금: 2억원 / 비과세소득: 5,000만원 / 소득공제: 없음
// 과세표준 계산 각사업연도 소득 = 15억원 이월결손금 한도 = 15억 × 80% = 12억 → 실제 2억 공제 비과세소득 = 5,000만원 과세표준 = 15억 - 2억 - 5,000만 = 12억5,000만원 // 산출세액 계산 2억 이하 → 2억 × 10% = 2,000만 2억~12.5억 → 10.5억 × 20% = 2억1,000만 산출세액 = 2,000만 + 2억1,000만 = 2억3,000만원
예제 2 — 중간예납세액 (직전연도 기준)
📋 문제
직전 사업연도 산출세액(가산세 포함): 6,000만원 / 감면세액: 500만원
원천징수세액: 200만원 / 수시부과세액: 100만원 / 직전 사업연도 12개월
// 중간예납세액 (§63의2①1) = (6,000만 - 500만 - 200만 - 100만) × 6/12 = 5,200만 × 0.5 = 2,600만원
예제 3 — 최저한세 적용
📋 문제
일반 내국법인 / 과세표준 80억원 / 산출세액 14억원
세액감면 2억원 / 세액공제 5억원
// 감면 후 세액 감면 후 세액 = 14억 - 2억 - 5억 = 7억원 // 최저한세액 (과세표준 80억 → 100억 이하 → 10%) 최저한세액 = 80억 × 10% = 8억원 // 검토 감면 후 세액(7억) < 최저한세액(8억) 미달액 = 1억원 → 1억원 만큼 감면 배제 → 세액공제부터 먼저 배제: 1억원 배제 후 나머지 4억은 이월공제 가능

출제 포인트 & 오답 함정 총정리

🎯 1차 최빈출 포인트 20선
  • 이월결손금 공제 한도: 80% (중소기업·회생기업 100%)

  • 외국납부세액공제 한도 초과분 이월: 10년

  • 경정에 따른 세액공제: 연간 20% 한도, 환급 대신 이월공제
  • 최저한세율: 중소기업 7% / 일반법인 100억 이하 10%, 1000억 초과 17%
  • 최저한세 배제 세액공제 → 10년 이월공제 가능

  • 중간예납: 사업연도 6개월 초과 법인, 기간 종료 후 2개월 이내
  • 직전 산출세액 0인 경우 → 실적 기준 강제
  • 중간예납세액 1천만원 초과 시 분납 가능

  • 과소신고 가산세(일반) 10% / (부정) 40%
