2. 인적공제 (§50·§51·§53)

2-1. 기본공제 (§50) — 1인당 연 150만원

💡 쉬운 비유: 부양하는 가족 1인당 연 150만원씩 과세소득에서 빼줍니다. 단, 소득이 너무 많거나 나이 요건이 안 맞으면 공제 불가!
대상자나이 요건소득 요건비고
본인제한 없음제한 없음항상 공제 (150만원)
배우자제한 없음소득금액 합계 100만원 이하
(근로소득만 있는 경우 총급여 500만원 이하)		사실혼 관계 배우자 불가

🚨 장애인은 나이 요건 없음!
§50①3호: "장애인에 해당하는 경우에는 나이의 제한을 받지 아니한다"
단, 소득 요건(100만원·500만원 이하)은 적용
⚠ 소득금액 100만원 vs 총급여 500만원:
소득금액 100만원 이하 = 원칙 (이자·배당·사업·연금·기타소득금액 합산)
근로소득만 있는 경우 → 총급여액 500만원 이하 (500만원 × (1-70%) ≈ 150만원 ≤ 100만원 아님, 총급여 기준 완화!)
단, 총급여 500만원 이하 = 근로소득공제 후 소득금액 약 150만원 → 100만원 기준 초과. 따라서 '근로소득만 있는 경우' 특칙으로 별도 500만원 기준 적용

3. 연금보험료공제 (§51의3) & 주택담보노후연금 이자비용공제 (§51의4)

3-1. 연금보험료공제 (§51의3①)

§51의3① 종합소득이 있는 거주자가 공적연금 관련법에 따른 기여금 또는 개인부담금(이하 "연금보험료")을 납입한 경우
→ 해당 과세기간에 납입한 연금보험료 전액을 종합소득금액에서 공제
구분내용
공제 대상국민연금·공무원연금·군인연금·사학연금 등 공적연금 관련법에 따른 기여금
공제 금액납입액 전액 (한도 없음)
공제 제한인적공제+연금보험료공제+주택담보노후연금이자비용공제+특별소득공제+조특법공제 합계가 종합소득금액 초과 시 → 연금보험료공제 미적용 처리 (§51의3③)
사업소득자국민연금 보험료 납입 시 연금보험료공제 적용 가능 (근로소득자 전용 아님)

3-2. 주택담보노후연금 이자비용공제 (§51의4)

§51의4① 연금소득이 있는 거주자가 대통령령 요건의 주택담보노후연금(역모기지론)을 받은 경우
→ 해당 과세기간에 발생한 이자비용 상당액을 연금소득금액에서 공제
한도: 200만원 / 연금소득금액 초과 불가 (§51의4①)
항목내용
적용 대상연금소득이 있는 거주자 (사업소득자·근로소득자에는 적용 불가)
공제 한도연 200만원 이하 (초과 시 200만원 공제)
적용 방식거주자가 신청한 경우에 적용 (§51의4②)
공제 대상 소득연금소득금액에서만 공제 (종합소득금액 전체 아님)
4. 특별소득공제 (§52) — 근로소득자 전용

4-1. 보험료 소득공제 (§52①) — 건강·고용·장기요양보험료

§52① 근로소득이 있는 거주자(일용근로자 제외)가 국민건강보험법·고용보험법·노인장기요양보험법에 따라 근로자가 부담하는 보험료를 지급한 경우
→ 그 전액을 근로소득금액에서 공제
✅ 근로자 부담분만 공제 (사용자 부담분은 급여에서 제외된 것이므로 별도)

6. 소득세 소득공제의 종합한도 (§51의3③ 준용)

6-1. 종합한도 개요

💡 쉬운 비유: 소득공제를 너무 많이 받으면 과세표준이 0 이하가 될 수 있어요. 그걸 방지하기 위해 특정 공제들의 합계가 2,500만원을 초과하면 초과분은 없는 것으로 봅니다.
소득공제 종합한도 = 2,500만원
§51의3③ 준용 다음 공제들의 합계가 2,500만원을 초과하는 경우 → 그 초과하는 금액만큼 공제하지 아니한다:
1. 인적공제 (기본공제 + 추가공제)
2. 연금보험료공제
3. 주택담보노후연금 이자비용공제
4. 특별소득공제
5. 조세특례제한법에 따른 소득공제
✅ 단, 인적공제(기본·추가)와 연금보험료공제는 종합소득금액 초과 불가 규정이 별도 적용
⚠ 종합한도 적용 시 먼저 기본공제·추가공제를 제외한 나머지 공제부터 한도 초과 여부 확인
(한도 내에서 어느 공제를 받을지 납세자가 선택 가능)
7. 종합소득공제의 특례와 배제 (§54·§54의2)

7-1. 종합소득공제의 배제 (§54)

상황적용 공제근거
분리과세 소득만 있는 자
(분리과세이자·배당·연금·기타소득만)		종합소득공제 전부 적용 안 됨§54①
과세표준 확정신고 미이행자
(§70④1호 서류 미제출)		기본공제 중 본인분만 + 표준세액공제만
(나중에 서류 제출하면 정상 적용)		§54②
수시부과 결정
(§82 수시부과)		기본공제 중 본인분만§54③
🚨 배제 요약:
분리과세 소득만 → 전부 배제
확정신고 미이행 → 본인 기본공제+표준세액공제만
수시부과 → 본인 기본공제만

7-2. 공동사업에 대한 소득공제 특례 (§54의2)

§54의2 §51의3(연금보험료공제) 또는 조특법 소득공제를 적용하거나 §59의3 세액공제를 적용하는 경우
§43③에 따라 합산과세되는 특수관계인이 지출·납입·투자·출자 등을 한 금액이 있으면
→ 주된 공동사업자의 소득에 합산과세되는 소득금액 한도에서
→ 주된 공동사업자가 지출 등을 한 금액으로 보아 주된 공동사업자의 소득공제·세액공제 적용 가능
✅ 합산과세 특수관계인이 납입한 연금보험료, 신용카드 사용액 등 → 주된 공동사업자가 공제받을 수 있음

종합소득과세표준 계산

甲(근로자, 총급여 8,000만원): 사업소득금액 500만원, 근로소득금액 5,000만원
배우자(소득 없음), 자녀 18세, 부친 65세(소득 없음), 모친 61세 장애인(소득 없음)
국민연금 납입: 400만원, 건강보험료(근로자부담): 300만원
장기주택저당차입금 이자: 600만원 (15년↑, 고정금리+비거치식)
①종합소득금액500 + 5,000 = 5,500만원
②기본공제본인+배우자+자녀(18세)+부친(65세)+모친(61세 장애인) = 5명 × 150만원 = 750만원
③추가공제모친 장애인 200만원 (장애인, 나이 제한 없음)
④연금보험료공제400만원 (전액)
⑤특별소득공제 (보험료)건강보험료 300만원 (전액)
⑥특별소득공제 (장기주택저당차입금)600만원 (한도 2,000만원 이내, 전액 공제 가능)
과세표준 = 5,500 − 750 − 200 − 400 − 300 − 600 = 3,250만원
⚠ 부친(65세)은 60세 이상 직계존속으로 기본공제 해당 / 자녀(18세)는 20세 이하로 기본공제 해당 / 모친은 장애인으로 나이 무관 기본공제+추가공제(200만원)

⚠️ 오답 함정 — 기출 기반 12선

❌
"배우자 소득금액이 150만원이면 기본공제 가능"

→ 기본공제 소득요건: 소득금액 합계 100만원 이하 (150만원 초과 → 불가)

❌
"총급여 600만원의 근로소득만 있는 배우자는 기본공제 불가"

→ 근로소득만 있는 경우 총급여 500만원 이하면 기본공제 가능. 600만원 → 불가 (§50①2)

❌
"장애인인 직계비속은 나이 요건 없이 기본공제 가능하나 소득 요건은 있다"

→ 정답: 장애인은 나이 요건만 없음. 소득 요건(100만원·500만원 이하)은 여전히 적용 (§50①3)

❌
"부녀자공제와 한부모공제 모두 해당하면 50만원+100만원 = 150만원 공제"

→ §51①단서: 중복 시 한부모공제(100만원)만 적용, 부녀자공제 배제

❌
"장기주택저당차입금 공제는 2주택 보유자도 받을 수 있다"

→ §52⑤2: 세대 구성원 보유 포함 2주택 이상 보유 시 공제 불가

❌
"주택임차차입금 원리금 상환액의 공제한도는 단독으로 400만원"

→ 조특법 §87②(청약저축 포함) 합계 400만원 한도. 청약저축 공제가 있으면 그만큼 임차차입금 공제 한도 감소

❌
"신용카드 공제율은 모두 15%"

→ 신용카드 15% / 직불·현금 30% / 대중교통·전통시장 40% / 도서·공연 30% (7천만원 이하 자)

❌
"과세기간 종료일(12.31) 현재 21세인 직계비속은 20세 이하 요건 불충족"

→ §53⑤: 나이 요건은 과세기간 중 해당 나이에 해당되는 날이 있으면 인정. 2025.3.1. 만 20세가 되었다면 2025년에 20세 이하인 날이 있음 → 공제 가능

❌
"주택담보노후연금 이자비용공제는 사업소득자도 받을 수 있다"

→ §51의4①: 연금소득이 있는 거주자만 적용. 사업소득자·근로소득자 적용 불가

❌
"분리과세소득만 있는 자도 기본공제는 받을 수 있다"

→ §54①: 분리과세이자·배당·연금·기타소득만 있는 자 → 종합소득공제 전부 불적용

❌
"장기주택저당차입금 이자는 원리금 합계에 대해 공제"

→ §52⑤: 이자 상환액만 공제 (원금 상환액 제외) / 주택임차차입금은 원리금 40%가 공제

❌
"기준시가 7억원 주택을 취득해도 장기주택저당차입금 공제 가능"

→ §52⑤: 취득 당시 기준시가 6억원 이하 주택만 해당
