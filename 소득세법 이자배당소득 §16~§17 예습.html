01

금융소득 전체 구조 개관

🍭 초등학생 비유
이자소득은 돈을 빌려줘서 받는 이자예요. 은행에 저금하면 받는 이자, 채권에서 받는 이자가 다 해당돼요.
배당소득은 회사에 돈을 투자(주주)해서 받는 수익이에요. 단, 세법은 실제 받는 배당 외에도 "받은 것처럼 보는 것"(의제배당)도 배당으로 처리해요!
구분소득세법상 위치소득금액 계산특이사항
이자소득 §16 총수입금액 = 소득금액
(필요경비 없음)		 직장공제회 초과반환금 포함
배당소득 §17 총수입금액 (+Gross-up) = 소득금액 Gross-up 적용 시 10% 가산
📌 이자·배당소득금액 = 필요경비 없음!
소득금액 = 총수입금액 (법 §16②, §17③)
예외: Gross-up 대상 배당소득 → 총수입금액 + 10% = 배당소득금액

이자소득의 범위 (§16①) 🔴 최빈출

# 이자소득 항목 세부 내용 근거
1 국가·지방자치단체가 발행한 채권·증권의 이자와 할인액 국채, 지방채 등 / 이자+할인액 모두 포함 §16①1
2 내국법인이 발행한 채권·증권의 이자와 할인액 회사채 등 §16①2
3 국내에서 받는 예금의 이자 적금·부금·예탁금·우편대체 포함 §16①3
4 신용계·신용부금으로 인한 이익 상호저축은행법 상의 신용계·신용부금 §16①4
5 외국법인 국내지점에서 발행한 채권·증권의 이자와 할인액 §16①5
6 외국법인이 발행한 채권·증권의 이자와 할인액 국외 채권 이자 포함 §16①6
7 국외에서 받는 예금의 이자 해외 예금 이자 §16①7
8 환매조건부(RP) 매매차익 대통령령으로 정하는 채권·증권의 환매조건부 매매차익 §16①8
9 저축성보험 보험차익 단, 10년 이상 보험 & 종신형 연금보험은 제외 §16①9
10 직장공제회 초과반환금 납입금 초과이익 + 반환금 추가이익
→ 분리과세 (종합과세 합산 안 함)		 §16①10
11 비영업대금의 이익 사금융 이자, 개인 간 금전 대여 이익
원천징수세율: 25%		 §16①11
12 유사 이자소득 1~11호와 유사, 금전 사용에 따른 대가 성격 §16①12
13 이자소득 + 파생상품 결합이익 이자소득 발생 거래·행위와 파생상품 결합 시의 이익 §16①13
🚨 이자소득에서 제외되는 것 — 기출 주의!
  • 장기저축성보험 (10년 이상): §16①9 단서 — 비과세
  • 종신형 연금보험 보험차익: §16①9나목 — 비과세
  • KOSPI200 선물 등 장내파생상품 거래 이익: 비열거 소득 → 이자소득 아님
  • 국채 통합발행 매각가액-액면가액 차액: 포함됨! (§16①1의 할인액)

이자소득 주요 항목 세부 해설

① 저축성보험 보험차익 — 비과세 vs 과세 구분
구분과세 여부요건
10년 이상 저축성보험비과세최초 납입일 ~ 만기/해지일까지 10년 이상 + 대통령령 요건
종신형 연금보험비과세대통령령으로 정하는 요건 충족 시
10년 미만 저축성보험이자소득 과세보험금-납입보험료 차익
🚨 기출 주의 (2024년 기출 반영)
2018년 가입 저축성보험(종신형 연금보험 아님), 납입 보험료 4,000만원, 만기보험금 5,000만원 수령
→ 가입시점부터 수령까지 6년 (10년 미만) → 보험차익 1,000만원 이자소득

배당소득의 범위 (§17①) 🔴 최빈출

2의2 법인과세 신탁재산으로부터 받는 배당금·분배금 법인세법 §5②에 따른 신탁재산 §17①2의2

5 집합투자기구로부터의 이익 공모·사모 펀드 수익 (사모집합투자기구 포함)

5의3 수익증권으로부터의 이익 금전 외 재산의 신탁 수익증권 §17①5의3
5의4 투자계약증권으로부터의 이익 자본시장법 §4⑥의 투자계약증권 §17①5의4

7 국제조세조정법에 따라 배당받은 것으로 간주된 금액 특정외국법인 유보소득 배당 간주 §17①7
8 출자공동사업자의 배당소득 공동사업 손익분배비율에 해당하는 금액
수입시기: 과세기간 종료일		 §17①8
🚨 배당소득 vs 비과세 판별 주의
  • 주식발행초과금 자본전입 무상주 → 원칙 비과세 (자본준비금 자본전입)

05

의제배당 6가지 유형 (§17②) 🔴 계산형 자주 출제

🍭 초등학생 비유
의제배당은 "실제 배당금을 안 줬지만, 세법이 배당받은 것으로 보는 것"이에요.
예를 들어 회사가 갑자기 없어지면서 주주에게 돈을 돌려줄 때, 처음 주식 살 때 쓴 돈보다 더 돌아오면 → 그 차이가 의제배당!

06

Gross-up (배당소득금액 가산) & 배당세액공제 (§17③) 🔴 계산형 핵심

🍭 초등학생 비유
회사는 이미 법인세를 낸 돈에서 배당을 줘요. 그런데 주주도 다시 소득세를 내면 이중과세가 돼요.
그래서 세법은 "배당받기 전에 법인세를 미리 낸 것처럼 더해서(Gross-up)" 세금을 계산하고, 이미 낸 법인세만큼 빼줘요(배당세액공제)!
① Gross-up 계산 구조
// 배당소득금액 계산 (§17③) 배당소득금액 = 총수입금액 + Gross-up금액 Gross-up금액 = 총수입금액 × 10% // 예: 배당금 100만원 수령 → 배당소득금액 = 100 + 10 = 110만원
② Gross-up 적용 대상 (§17③ 본문 단서)
✓ Gross-up 적용 대상
  • 내국법인 이익·잉여금 배당(§17①1)
  • 법인으로 보는 단체 배당(§17①2)
  • 법인과세신탁재산 배당(§17①2의2)
  • 의제배당(§17①3) — 일부 제외 있음
  • 법인세법 처분 배당(§17①4)
  • 집합투자기구 이익 중 일부(§17①5)
✕ Gross-up 제외 대상 (§17③ 단서)
  • 법인세 미과세 배당 (자본감소 의제배당)
  • 자기주식 소각이익 자본전입 의제배당
  • 토지 재평가차액 자본전입 의제배당
  • 자기주식 보유 지분율 증가 의제배당(§17②5)
  • 최저한세 비과세·면제 법인 배당소득
  • 재평가적립금 위반 감액 배당
  • 법인세법 §18⑧ 자본준비금 감액 배당
  • 출자공동사업자 배당소득(§17①8) → 제외
③ 금융소득 2,000만원 기준과 Gross-up 관계 (§14④)
소득세법 제14조 제4항 이자소득등의 종합과세기준금액(2,000만원) 계산 시
배당소득에는 Gross-up 금액을 포함하지 않는다
// 종합과세 판단 시 2,000만원 계산 기준금액 = 이자소득 + 배당소득(수령액 원금 기준, Gross-up 제외) IF 기준금액 ≤ 2,000만원: 분리과세 (원천징수로 납세의무 종결) IF 기준금액 > 2,000만원: 종합과세 (종합소득에 합산) // 종합과세 시 소득금액 종합과세 배당소득금액 = 수령액 + Gross-up(10%)
④ 배당세액공제 (§56)
// 배당세액공제 (이중과세 조정) 배당세액공제액 = Gross-up 금액 = 배당소득 × 10% // 종합과세할 배당소득이 있는 경우 산출세액에서 공제 // 공제 후 세액이 음수가 되면 0으로 처리 (환급 없음)

계산 예제 (기출 유형 반영)

예제 1 — 배당소득금액 계산 (2021년 기출 유사)
📋 문제
거주자 甲의 다음 배당소득에 대해 종합과세할 배당소득금액을 계산하시오. (이자소득 별도 10,000,000원 있음, 원천징수 적법)
① 내국 비상장법인 금전배당: 15,000,000원
② 법인세법에 따라 처분된 배당소득: 4,000,000원
③ 자기주식 소각이익 자본전입 무상주(소각일로부터 2년 내): 8,000,000원
④ 외국법인 배당소득: 3,000,000원
⑤ 감자로 인한 의제배당: 6,000,000원
⑥ 출자공동사업자 배당소득: 2,000,000원
⑦ 주식발행초과금 자본전입 무상주: 1,000,000원
// Step 1: 각 항목 배당소득 해당 여부 확인 ① 내국법인 배당 15,000,000 → 배당소득 ✓ ② 법인세처분 배당 4,000,000 → 배당소득 ✓ ③ 자기주식소각이익(2년내) 8,000,000 → 의제배당 ✓ ④ 외국법인 배당 3,000,000 → 배당소득 ✓ ⑤ 감자 의제배당 6,000,000 → 배당소득 ✓ ⑥ 출자공동사업자 2,000,000 → 배당소득 ✓ ⑦ 주발초과금 무상주 1,000,000 → 비과세 ✗ // Step 2: 종합과세 기준 판단 (이자+배당, Gross-up 제외) 금융소득 합계 = 이자소득 10,000,000 + 배당소득 (①+②+③+④+⑤+⑥) = 38,000,000 합계 = 48,000,000원 > 2,000만원 → 종합과세 // Step 3: Gross-up 대상 판별 Gross-up O: ① 15,000,000 ② 4,000,000 ④ 3,000,000 ⑤ 6,000,000 Gross-up X: ③ 자기주식소각이익(2년내) 8,000,000 → §17③2호 제외 ⑥ 출자공동사업자 2,000,000 → §17③에서 제외 Gross-up 기준액 = 15,000,000 + 4,000,000 + 3,000,000 + 6,000,000 = 28,000,000 Gross-up 금액 = 28,000,000 × 10% = 2,800,000원 // Step 4: 종합과세 배당소득금액 배당소득금액 = 38,000,000 + 2,800,000 = 40,800,000원
예제 2 — 집합투자기구 이익 배당소득 계산 (2024년 기출 유사)
📋 문제
공모투자신탁 환매이익 12,000,000원 (구성: 회사채 양도차손 △3,000,000원, 코스닥 상장법인 주식 매매차익 10,000,000원, 비상장법인 주식 매매차익 5,000,000원)
→ 배당소득에 포함될 금액은?
// 집합투자기구(공모펀드) 이익 배당소득 계산 전체 환매이익 12,000,000 코스닥 상장 내국법인 주식 매매차익 차감: -10,000,000 (비과세) // 상장내국법인 주식 매매차익은 배당소득 제외 배당소득 = 12,000,000 - 10,000,000 = 2,000,000원 // 회사채 양도차손(-3,000,000)은 이미 환매이익(12,000,000)에 반영됨 // 비상장주식 매매차익 5,000,000은 배당소득에 포함 (이미 12,000,000에 포함)

출제 포인트 & 오답 함정 총정리

🎯 1차 최빈출 포인트 20선 (5년 14문제 반영)
  • 이자소득금액 = 총수입금액 (필요경비 없음)
  • 저축성보험 보험차익: 10년 이상 비과세 / 10년 미만 이자소득
  • 직장공제회 초과반환금: 이자소득 + 분리과세 (종합합산 안 함)
  • 비영업대금의 이익 원천징수율: 25% (일반이자 14%와 구별)
  • P2P(온라인투자연계) 이자 → 비영업대금이익 아님 (일반이자 14%)
  • 공모펀드(집합투자기구) 이익 → 배당소득 / 단, 상장내국법인 주식 매매차익 제외
  • 이익잉여금 자본전입 무상주 → 의제배당
  • 주식발행초과금 자본전입 무상주 → 비과세
  • 자기주식 소각이익 자본전입 2년 이내 → 의제배당 (Gross-up 제외)
  • 자기주식 소각이익 자본전입 2년 초과 → 비과세
  • 취득가액 불분명 → 액면가액으로 봄
  • Gross-up 금액 = 배당금 × 10%
  • 출자공동사업자 배당소득(§17①8) → Gross-up 제외
  • 종합과세 판단: 이자+배당(Gross-up 제외) 합계 2,000만원 초과 여부
  • 금융소득 2,000만원 이하 → 분리과세
  • 잉여금 처분 배당 수입시기 → 처분결의일 (과세기간 종료일 아님)
  • 법인세법 처분 배당 수입시기 → 결산확정일
  • 출자공동사업자 배당소득 수입시기 → 과세기간 종료일
  • 통지예금 이자 수입시기 → 인출일
  • 합병 의제배당 수입시기 → 합병등기일
⚠ 자주 나오는 오답 함정 비교표
오답 선지정답
"직장공제회 초과반환금은 종합소득에 합산" 오답 — 분리과세 (§14③3)
"비영업대금 이익 원천징수율 14%" 오답 — 25%
"P2P(온라인투자연계) 이자는 비영업대금이익" 오답 — 일반이자소득 14% 적용
"자기주식 소각이익 2년 초과 자본전입 → 의제배당" 오답 — 2년 이내만 의제배당, 2년 초과는 비과세
"출자공동사업자 배당소득에 Gross-up 적용" 오답 — Gross-up 제외 (§17①8 제외됨)
"잉여금 처분 배당 수입시기 = 과세기간 종료일" 오답 — 처분결의일 (과세기간 종료일은 출자공동사업자)
"Gross-up 적용 후 금액 기준 2,000만원 판단" 오답 — Gross-up 제외한 원금 기준으로 판단
"상장법인 주식 매매차익도 집합투자기구 배당소득에 포함" 오답 — 상장 내국법인 주식 매매차익은 제외
