01

제도 개요 및 구조 파악

🍭 초등학생 비유
회사가 나중에 직원들에게 줄 퇴직금을 미리 저금통에 넣어두는 것이 퇴직급여충당금이에요.
그런데 세금 계산을 할 때는 "저금통에 얼마까지 넣을 수 있나?" 하는 한도가 있어요.
그 한도를 넘으면 세금 계산에서 뺄 수 없고, 나중에 실제로 퇴직금을 줄 때 저금통에서 먼저 쓰는 거예요!

법인세법 제33조 제1항 (2026.01.02 시행) — 결산조정 요건 내국법인이 각 사업연도의 결산을 확정할 때 임원이나 직원의 퇴직급여에 충당하기 위하여 퇴직급여충당금을 손비로 계상한 경우에 한하여 손금에 산입한다.
🚨 핵심 — 결산조정 vs 신고조정
퇴직급여충당금은 결산조정 항목 → 결산 확정 시 장부에 비용으로 계상해야만 손금산입 가능.
세무조정계산서에만 기재하는 신고조정(임의 조정)으로는 절대 처리 불가.
⚠ 시험 선지: "신고조정으로 손금 산입할 수 있다" → 오답
02

퇴직급여충당금 — 설정 시 세무조정

① 한도 계산 구조
법인세법 시행령 제60조 제1항·제2항 ①항 한도 (당기 한도): 퇴직급여 지급대상 임원·직원에게 해당 사업연도에 지급한 총급여액 × 5%
②항 한도 (누적 한도): 전원 퇴직 시 퇴직금 추계액 × 해당 연도 비율에서 기설정 누적액을 공제한 금액
→ 두 한도 중 작은 금액이 당기 손금산입 한도
// ① 당기 한도 당기 한도 = 당기 총급여액(DC형 제외) × 5% // ② 누적 한도 (2016년 이후) 누적 한도 = 퇴직금 추계액 × 0% - 기설정 누적액 = 음수 또는 0 // → 손금산입 가능 한도 세법상 한도 = MIN(당기 한도, 누적 한도) = 0원 (2016년 이후 사실상 0)
⚡ 누적 비율 단계적 축소 (수험 암기)

③ 총급여액의 범위
시행령 제60조 제1항 / 제44조 제4항 제2호 총급여액 = 소득세법 §20①1·2의 금액(비과세소득 제외) 중 DC형 퇴직연금 설정자 제외한 임원·직원에게 지급한 금액
  • DC형(확정기여형) 설정자는 총급여액에서 제외 → 5% 한도 계산 시 분모에서 빠짐
  • 비과세소득(식대, 자가운전보조금 등)은 총급여액에서 제외
  • 손금불산입된 임원 인건비도 제외
03

퇴직급여충당금 — 지급(사용) 시 세무조정

🍭 초등학생 비유
저금통(충당금)에서 퇴직금을 꺼내 줄 때, 저금통에 있는 돈부터 먼저 쓰는 거예요.
만약 저금통이 비었는데 퇴직금을 더 줘야 하면, 그때는 새 돈(비용)으로 처리해요!
① 현실적 퇴직의 요건 (손금 인정 전제)
시행령 제44조 제1항·제2항 퇴직급여는 현실적으로 퇴직하는 경우에 지급하는 것에 한하여 손금산입
  • 직원 → 임원으로 취임 시 (실제 지급한 경우)
  • 조직변경·합병·분할·사업양도로 퇴직한 경우
  • 근로자퇴직급여보장법 §8②에 따른 중간정산 시
  • 정관 또는 퇴직급여지급규정에 따른 임원 중간정산 (장기요양 등)
② 지급 시 세무조정 3가지 패턴
패턴장부 처리세무조정처분

③ 충당금 잔액의 익금환입 — 해당 없음!
시행령 제60조 제3항 손금산입 누적액에서 지급한 퇴직금을 뺀 금액이 추계액 × 비율을 초과하더라도 그 초과액은 익금으로 환입하지 아니한다.
  • 퇴직금 지급 후 세무상 충당금 잔액이 있더라도 자동 익금환입 없음
  • 다음 사업연도 한도 계산 시 기설정 누적액에 포함되어 자연스럽게 조정
04

합병·사업양도 시 충당금 승계 (법 §33③④)

법인세법 제33조 제3항·제4항 합병·분할 등기일 현재 퇴직급여충당금 중 합병법인등이 승계받은 금액 → 합병법인등의 퇴직급여충당금으로 간주
사유처리
합병·분할 합병(분할)등기일 현재 충당금 → 합병법인등에 승계
승계받은 법인의 충당금으로 취급
사업의 포괄적 양도 합병·분할과 동일하게 준용
⚡ 출제 포인트
  • 승계받은 금액은 합병법인등이 별도로 손금산입하지 않아도 충당금으로 인정
  • "포괄적 양도" 시에도 적용 — 개별 자산양도 시에는 적용 없음
05

퇴직연금충당금(확정급여형 DB) — 설정 시 세무조정

① 손금산입 한도 계산
시행령 제44조의2 제4항 확정급여형(DB) 부담금 손금산입 한도 = MAX(①, ①의2) − 직전 연도까지 지급한 부담금 누계
// ①항: 추계액 기준 ① = 퇴직금 추계액(DC형·임원한도초과 제외) - 사업연도종료일 현재 퇴직급여충당금 // ①의2항: 근퇴법 기준 (IAS19) ①의2 = 근퇴법 §16①1 금액 + 가입 안 한 자 추계액 + 일부 미가입 기간 추계액 - 사업연도종료일 현재 퇴직급여충당금 // 최종 손금산입 한도 한도 = MAX(①, ①의2) - 직전연도말까지 손금산입 부담금 누계액 → 한도 초과분: 손금불산입(유보)
② 세무조정 패턴
상황세무조정
납입액 ≤ 한도 전액 손금산입 (조정 없음)
납입액 > 한도 초과분 손금불산입 (유보)
퇴직 시 수급 연금 지급 → 퇴직급여충당금에서 먼저 차감 (법 §33② 준용)
✅ 확정급여형 vs 퇴직급여충당금 관계
  • DB형 한도 계산 시 분모에서 이미 설정된 퇴직급여충당금을 차감 → 충당금이 많을수록 DB형 손금한도 줄어듦
  • 두 방식은 중복 공제 방지 구조로 설계됨
06

확정기여형(DC) 퇴직연금 — 처리 방법

시행령 제44조의2 제3항 확정기여형(DC) 부담금은 전액 즉시 손금산입 (한도 없음)
✓ 직원
DC형 부담금 → 전액 손금
별도 한도 계산 없음
세무조정 불필요
⚠ 임원
부담금 합계를 퇴직급여로 보아 임원 퇴직급여 한도(령 §44④) 적용
한도 초과 시 → 퇴직일 속하는 사업연도 부담금에서 손금불산입
초과액이 당기 부담금 초과 시 → 익금산입
🚨 오답 함정
"DC형은 임원에게도 전액 손금" → 오답
직원은 전액 손금이지만, 임원에 대한 DC형 부담금은 퇴직급여 한도 적용!
07

임원 퇴직급여 손금 한도 (시행령 §44④)

정관에 금액이 정해진 경우 (§44④1호)
한도 = 정관에 정해진 금액
정관에서 위임된 퇴직급여지급규정이 있으면 그 금액
정관에 없는 경우 (§44④2호)
한도 = 1년치 총급여액 × (1/10) × 근속연수
퇴직일 기준 소급 1년간 총급여 × 1/10 × 근속연수
// 정관 규정 없을 때 임원 퇴직급여 한도 한도액 = (퇴직 전 1년간 총급여액 × 1/10) × 근속연수 // 직원 기간 합산 가능 여부 직원 → 임원 취임 시 퇴직금 미지급한 경우: 직원 근속기간 합산 가능
⚡ 출제 포인트
  • 한도 계산 시 총급여액 = 비과세 제외, 손금불산입 인건비 제외
  • 지배주주등과 특수관계인 임원 → §44④ 적용 BUT §44③ 안분 규정은 지배주주등 제외
  • 임원 퇴직급여 한도 초과분 → 손금불산입 (기타사외유출)

계산 예제

예제 1 — 충당금 설정 세무조정
📋 문제
(주)세무는 2026년 사업연도에 퇴직급여충당금 500만원을 비용으로 계상하였다.
DC형 제외 임직원 총급여액: 8,000만원 / 기설정 충당금 누적액: 200만원 / 전원 퇴직 시 추계액: 5,000만원
// ① 당기 한도 당기 한도 = 8,000만원 × 5% = 400만원 // ② 누적 한도 (2026년 → 비율 0%) 누적 한도 = 5,000만원 × 0% − 200만원 = −200만원 → 0원 // 손금산입 한도 세법 한도 = MIN(400만, 0원) = 0원 // 세무조정 손금불산입 = 500만원 − 0원 = 500만원 손금불산입(유보)
예제 2 — 퇴직금 지급 시 세무조정
📋 문제
당기에 직원 A 퇴직. 퇴직금 1,200만원 지급.
기초 세무상 퇴직급여충당금(유보) 잔액: 800만원
// 충당금에서 먼저 지급 (법 §33②) 충당금에서 지급 = 800만원 → 유보 800만원 감소(익금불산입) // 나머지 400만원: 비용(퇴직급여)으로 계상 초과 지급분 = 1,200만원 − 800만원 = 400만원 → 비용으로 손금산입 (별도 조정 없음) // 세무조정 요약 익금불산입 800만원 (△유보) 추가 손금 400만원 (조정 없음 — 그대로 손금)
예제 3 — 임원 퇴직급여 한도 계산
📋 문제
임원 B: 퇴직 전 1년 총급여액 6,000만원 / 근속연수 10년 / 정관 규정 없음 / 실제 퇴직금 지급액 8,000만원
// 한도 계산 (령 §44④2호) 한도 = 6,000만원 × (1/10) × 10년 = 6,000만원 // 세무조정 실제 지급액 = 8,000만원 손금불산입 = 8,000만원 − 6,000만원 = 2,000만원 (기타사외유출)

출제 포인트 & 오답 함정 총정리

🎯 1차 최빈출 포인트 12선
  • 퇴직급여충당금은 결산조정 항목 — 신고조정 불가
  • 당기 한도 = 총급여액 × 5% (DC형 제외 임직원)
  • 2016년 이후 누적 한도 비율 = 0% → 신규 설정 사실상 불가
  • DC형 설정자는 5% 한도 계산 총급여에서 제외
  • 퇴직금 지급 시 → 충당금에서 먼저 차감 (법 §33②)
  • 충당금 초과 지급분 → 그대로 비용 (별도 조정 없음)
  • 충당금 잔액은 자동 익금환입 없음 (§60③)
  • DC형 부담금: 직원 → 전액 손금 / 임원 → 한도 적용
  • 임원 퇴직급여 한도(정관 없음) = 1년 총급여 × 1/10 × 근속연수
  • 임원 한도 초과 → 손금불산입, 처분 = 기타사외유출
  • 합병·분할 시 충당금 승계 가능 (포괄양도도 준용)
  • 현실적 퇴직이 아닌 경우 지급한 퇴직금 → 손금불산입
