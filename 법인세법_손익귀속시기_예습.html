01

일반 원칙 — 권리의무확정주의

🍭 초등학생 비유
회사가 물건을 팔았을 때 "세금은 언제 내야 하나?"를 결정하는 게 귀속시기예요.
세법은 "돈을 받은 날"도, "약속한 날"도 아니라 "이제 확실히 내 수입이 됐다고 인정받는 날"을 기준으로 해요 — 이게 바로 권리의무확정주의입니다!
원칙내용비교
현금주의 실제로 현금이 들어온·나간 날 법인세법 원칙 ✕
발생주의 (기업회계) 거래가 경제적으로 발생한 날 기업회계 기준
권리의무확정주의 (법인세) 익금·손금이 법적으로 확정된 날 법인세법 원칙 ✓
📌 권리의무확정주의의 의미
  • 익금: 수익을 실현할 권리가 확정된 시점
  • 손금: 비용·손실을 부담할 의무가 확정된 시점
  • 원칙적으로 기업회계의 발생주의와 유사하지만, 구체적인 귀속 시점은 세법령이 별도 규정
  • 기업회계와 세법의 귀속시기가 다를 경우 → 세법 우선 적용
⚡ 결산조정 vs 신고조정과의 관계
귀속시기 규정은 익금·손금의 귀속 사업연도를 결정함
→ 결산서에 수익·비용을 어느 연도에 계상했느냐와 달리, 세법은 확정된 날 기준으로 독립적으로 판단
단, 일부 항목은 결산 계상을 요건으로 하는 예외 존재 (이하 각 항목 참조)

자산 판매·양도 손익의 귀속시기 (시행령 §68①)

거래 유형 귀속시기 (원칙) 예외·특이사항 근거
상품·제품 등
일반 판매		 인도한 날 반환조건부·동의조건부·기한부 판매 → 조건 성취일 또는 기한 경과일 령 §68①1
시용(試用) 판매 상대방이 구입 의사를 표시한 날 일정 기간 내 반송·거절 없으면 판매 확정 → 그 기간의 만료일 령 §68①2
상품 외 자산 양도
(부동산·유가증권 등)		 대금 청산일 대금 청산 전에 ① 소유권이전등기·등록, ② 인도, ③ 사용수익 중 빠른 날 령 §68①3
위탁매매 수탁자가 위탁자산을 매매한 날 위탁자 기준으로 수탁자 매매일이 귀속시기 령 §68①4
증권시장 유가증권
보통거래		 매매계약 체결일 결제일(T+2) 아님! 계약 체결일 기준 령 §68①5
① 상품 외 자산(부동산) 양도 — 귀속시기 판단 흐름
부동산 양도 귀속시기는?
→
원칙: 대금 청산일
→
BUT 대금 청산 전에 아래 중 하나라도 먼저 발생하면:
①
소유권이전등기일(등록일)
②
인도일
③
사용수익일
→
① ② ③ 중 가장 빠른 날이 귀속시기
🚨 부동산 귀속시기 — 최빈출 오답 함정
  • "부동산 양도는 항상 등기일이 귀속시기" → 오답
    대금 청산일이 원칙! 등기일은 대금 청산 전 등기 시에만 적용
  • "인도일이 등기일보다 빠르면 인도일" → 정답
    인도일·등기일·사용수익일 중 가장 빠른 날
  • 대금을 먼저 전부 받고 나중에 등기하는 경우 → 대금 청산일
② 조건부 판매·시용판매 비교
반환·동의·기한부 조건부 판매
인도일 아님!
→ 조건이 성취되거나 기한이 지나 판매가 확정된 날
예: 조건 불성취 시 반환 가능 → 아직 수익 미확정
시용(試用) 판매
원칙: 구입 의사 표시일
특약: 거절 기간의 만료일
예: "2주 내 반송 없으면 구매 확정" → 2주 만료일
③ 매출할인 귀속시기 (령 §68⑤)
시행령 제68조 제5항 매출할인 금액은 약정에 의한 지급기일이 속하는 사업연도 매출액에서 차감
지급기일 미정 시 → 지급한 날이 속하는 사업연도
⚡ 매출할인 처리 요점
매출할인 = 매출 차감항목 (손금 아님)
귀속시기 = 지급기일 (지급일 아님!)
03

장기할부 판매의 귀속시기 특례 (시행령 §68②~④)

① 장기할부조건의 정의 (령 §68④)
시행령 제68조 제4항 판매금액·수입금액을 2회 이상 분할 수입하는 것 중
목적물 인도일의 다음날부터 최종 할부금 지급기일까지의 기간이 1년 이상인 것
🚨 장기할부조건 요건 — 2가지 모두 충족!
요건 ①
2회 이상 분할 수입
1회 지급이면 해당 없음
요건 ②
인도일 다음날 ~ 최종 할부금 지급기일 1년 이상
1년 미만이면 해당 없음
② 장기할부 특례 — 일반법인 vs 중소기업
구분원칙 귀속시기장기할부 특례특례 적용 조건
일반 내국법인 인도일 (상품) 또는
대금청산일 등 (기타자산)		 회수하였거나 회수할 금액 기준
각 연도 익금 산입		 결산 계상 必
(인도일 속 사업연도 결산 시 해당연도 회수액 수익계상)
중소기업 ← 동일 ← 동일 임의 적용 (할 수 있다)
🚨 일반법인과 중소기업 차이 — 시험 핵심!
일반 내국법인
결산 계상 → 의무 적용
"계상한 경우에는 … 산입한다"
결산 계상 안 하면 원칙 귀속시기 적용
중소기업
선택 적용 가능
"… 산입할 수 있다"
결산 계상 안 해도 선택 가능
③ 인도일 이전 회수액 및 폐업 시 처리 (령 §68③)
상황처리
인도일 이전 회수액 인도일에 회수한 것으로 간주 → 인도일 속 사업연도 익금
장기할부 중 폐업 폐업일 현재 미산입 금액과 대응 비용 → 폐업일 속 사업연도 전액 익금·손금
④ 현재가치할인차금 환입 (령 §68⑥)
시행령 제68조 제6항 장기할부 채권에 현재가치할인차금 계상 시
→ 기업회계기준에 따라 채권 회수기간 동안 환입하였거나 환입할 금액을 각 사업연도 익금에 산입
04

용역 제공 손익의 귀속시기 (시행령 §69)

🍭 초등학생 비유
집을 지어주는 공사처럼 오랜 기간이 걸리는 작업은 완성된 날에 한꺼번에 수익을 잡는 게 아니라, "공사를 얼마나 진행했는지(진행률)"에 따라 매년 조금씩 나눠서 수익을 인식해요 — 이게 작업진행률 기준입니다!
① 원칙: 작업진행률 기준 (령 §69①)
시행령 제69조 제1항 건설·제조·기타 용역(도급공사·예약매출 포함)의 제공 손익
→ 착수일 속 사업연도 ~ 인도일(용역완료일) 속 사업연도까지
→ 작업진행률 기준으로 수익·비용 각 사업연도 익금·손금 산입
// 작업진행률 기준 수익 인식 당기 인식 수익 = 도급금액 × 작업진행률 - 직전연도까지 인식한 수익 작업진행률 = 발생원가 누계 / 추정 총원가 // 예: 도급금액 10억, 총원가 추정 8억, 당기 발생원가 2억 // 진행률 = 2억/8억 = 25%, 당기 수익 = 10억 × 25% = 2.5억
② 인도기준(완성기준) 선택 가능한 예외 (령 §69①단서)
예외 ① — 중소기업 + 1년 미만 계약
중소기업이 수행하는 계약기간 1년 미만 건설 등
→ 인도일 속 사업연도 익금·손금 산입 선택 가능
예외 ② — 기업회계기준상 인도기준 계상
기업회계기준에 따라 인도일 속 사업연도 수익·비용으로 결산 계상한 경우
→ 인도기준 허용
🚨 예외 ① 정확한 요건 — 두 가지 모두 충족!
  • ① 중소기업이어야 함 (일반법인은 인도기준 불가)
  • ② 계약기간이 1년 미만이어야 함
  • → 중소기업이어도 1년 이상 계약이면 진행기준 의무
  • → 1년 미만이어도 일반법인이면 진행기준 의무
③ 진행률 계산 불능 시 (령 §69②)
시행령 제69조 제2항 작업진행률을 계산할 수 없다고 인정되는 경우 → 인도일 속 사업연도에 익금·손금 산입
④ 공사 계약 해약 시 (령 §69③)
시행령 제69조 제3항 진행기준으로 인식한 익금·손금과 해약으로 확정된 금액에 차액 발생
→ 그 차액을 해약일 속 사업연도의 익금·손금에 산입
⑤ 용역 제공 귀속시기 판단 흐름도
건설·도급·예약매출 등 용역인가?
→
원칙: 작업진행률 기준
→
예외 가능한가?
①
중소기업 + 1년 미만 계약 → 인도기준 선택 가능
②
기업회계기준상 인도기준으로 결산 계상 → 인도기준 허용
③
진행률 계산 불능 → 인도기준 적용

이자·배당 등 금융 손익의 귀속시기 (시행령 §70)

① 이자소득·이자비용 귀속시기 (령 §70①)

이자 수입

(선수입이자 제외)		 경과 이자 계상 시 → 계상 사업연도 익금 령 §70①1
이자 지급
(손금)		 소득세법 시행령 §45에 따른 수입시기 결산 확정 시 경과 이자 계상→ 계상 사업연도 손금
단, 특수관계인 + 차입일~지급일 1년 초과 시 제외!		 령 §70①2
🚨 이자 지급 손금 예외 — 특수관계인 1년 초과 제한
차입일부터 이자지급일까지 1년을 초과하는 특수관계인과의 거래에 따른 이자·할인액은
경과 이자 계상하더라도 결산 계상 = 손금 인정 특례 적용 불가
→ 소득세법 시행령 §45에 따른 수입시기 기준 적용 강제
② 배당소득 귀속시기 (령 §70②)
시행령 제70조 제2항 배당금 수입 → 소득세법 시행령 §46에 따른 수입시기가 속하는 사업연도 익금
예외: 금융회사 등이 신용회복지원 유동화전문회사로부터 받는 배당 → 실제 지급받은 날
⚡ 소득세법 시행령 §46 배당 수입시기 핵심
배당 종류수입시기
잉여금 처분에 의한 배당해당 법인의 잉여금 처분 결의일
건설이자 배당지급일
무기명 주식 배당지급일
③ 보험료 등 금융업 수입 (령 §70③)
항목귀속시기비고
보험료·부금·보증료·수수료 (금융·보험업)실제로 수입된 날선수입분 제외
경과 보험료 등 결산 계상계상 사업연도경과 기간 대응 금액
증권 매매 수수료
(투자매매·중개업자, 정형화 거래)		매매계약 체결일결제일 아님!
④ 이자소득 귀속시기 핵심 비교
법인 유형이자 수입 귀속 원칙경과이자 계상 특례
일반 법인 소득세법령 §45 수입시기 결산 계상 → 계상 사업연도 익금
(원천징수 이자 제외)
금융·보험업 법인 실제로 수입된 날 결산 계상 → 계상 사업연도 익금

임대료 등 기타 손익의 귀속시기 (시행령 §71)

① 임대료 귀속시기 (령 §71①)
상황귀속시기예외
임대료 지급일이 정해진 경우계약에 따른 지급일결산 시 경과 임대료 계상 → 계상 사업연도 익금·손금
또는 지급기간 1년 초과 시 경과분 각 사업연도 귀속
임대료 지급일이 정해지지 않은 경우지급을 받은 날
⚡ 임대료 1년 초과 기간 특례
임대료 지급기간이 1년을 초과하는 경우 → 이미 경과한 기간에 대응하는 임대료 상당액은 해당 사업연도 익금
→ 이자소득의 경과이자 계상 특례와 유사한 구조
② 사채할인발행차금 손금 귀속 (령 §71③)
시행령 제71조 제3항 사채할인발행차금 = 상환액 합계 − 사채발행가액(발행수수료·직접비용 차감 후)
→ 기업회계기준에 의한 상각방법에 따라 손금산입
③ 파생상품 손익 귀속시기 (령 §71⑥)
시행령 제71조 제6항 목적물 인도 없이 차액 금전 정산하는 파생상품 거래 손익
→ 그 거래에서 정하는 대금결제일이 속하는 사업연도
④ 자산유동화·매출채권 배서양도 (령 §71④)
시행령 제71조 제4항 자산유동화법에 따른 보유자산 양도, 매출채권·받을어음 배서양도

계산 예제

예제 1 — 부동산 양도 귀속시기 판단
📋 문제
(주)세무는 2026년 9월 1일 토지를 3억원에 양도 계약하였다.
계약금: 2025.12.01 수령 / 중도금: 2026.06.01 수령 / 잔금: 2026.10.01 수령
소유권이전등기: 2026.08.01 / 인도: 2026.09.01
→ 귀속 사업연도는?
// 부동산(상품 외 자산) 양도 귀속시기 판단 (령 §68①3) 원칙: 대금 청산일 = 잔금일 2026.10.01 → 2026년 // 대금 청산 전 선행 사건 확인 소유권이전등기: 2026.08.01 → 대금 청산(10.01) 이전! 인도: 2026.09.01 → 대금 청산 이전 // 등기일, 인도일, 사용수익일 중 가장 빠른 날 등기일 2026.08.01 < 인도일 2026.09.01 → 귀속 사업연도: 2026년 (등기일 2026.08.01이 기준)
예제 2 — 장기할부 판매 귀속시기 (일반법인)
📋 문제
일반 내국법인이 2026.01.01 기계장치를 장기할부로 판매(총 대금 12억, 인도일 2026.01.01)
할부 조건: 매년 말 3억씩 4회 수령 (2026~2029년)
회사는 인도일 속 사업연도 결산 시 2026년에 3억만 수익 계상함
// 장기할부 조건 확인 분할횟수: 4회 ≥ 2회 ✓ 기간: 2026.01.01 ~ 2029.12.31 = 약 4년 ≥ 1년 ✓ → 장기할부 해당 // 일반법인 — 결산 계상 시 특례 적용 2026년 결산에 3억 수익 계상 → 2026년 3억 익금 2027년 결산에 3억 수익 계상 → 2027년 3억 익금 // (결산 계상 필수 — 안 하면 인도일 기준 전액 귀속)
예제 3 — 용역(진행률 기준) 손익 귀속
📋 문제
도급공사 계약: 도급금액 20억, 추정 총원가 16억
2026년 발생원가 4억 (누계), 2027년 발생원가 8억 (누계), 2028년 공사 완료 (원가 4억 추가)
// 2026년 진행률 = 4억/16억 = 25% 인식 수익 = 20억 × 25% = 5억원 // 2027년 진행률 = 8억/16억 = 50% 인식 수익 = 20억 × 50% - 5억(기인식) = 5억원 // 2028년 (완료) 총 인식 = 20억 - 5억 - 5억 = 10억원

출제 포인트 & 오답 함정 총정리

🎯 1차 최빈출 포인트 18선
  • 법인세법 귀속시기 원칙 = 권리의무확정주의 (현금주의 아님)
  • 상품·제품 판매 원칙 = 인도한 날
  • 반환·동의·기한부 조건부 판매 = 조건 성취일 또는 기한 경과일
  • 시용판매 = 구입 의사 표시일 / 특약 있으면 거절 기간 만료일
  • 부동산 등 기타 자산 양도 원칙 = 대금 청산일
  • 부동산 대금 청산 전 등기·인도·사용수익 → 그 중 가장 빠른 날
  • 위탁매매 = 수탁자가 매매한 날
  • 증권시장 보통거래 = 매매계약 체결일 (결제일 아님)
  • 장기할부 요건: 2회 이상 분할 + 1년 이상
  • 일반법인 장기할부 특례 = 결산 계상 시 의무 적용
  • 중소기업 장기할부 특례 = 임의 적용 (선택)
  • 건설·도급·예약매출 원칙 = 작업진행률 기준
  • 중소기업 + 1년 미만 계약 → 인도기준 선택 가능
  • 일반법인 장기 건설공사 → 진행기준 의무
  • 이자 수입(일반법인) = 소득세법령 §45 수입시기 / 경과이자 계상 시 계상연도 익금
  • 이자 수입(금융·보험업) = 실제 수입된 날
  • 특수관계인 이자 지급 (차입~지급 1년 초과) → 경과이자 계상 특례 배제
  • 임대료 = 계약상 지급일 / 지급일 미정 시 실제 지급받은 날

"1년 미만 건설공사라면 모든 법인이 인도기준 가능" 오답 — 중소기업만 인도기준 선택 가능
"이자 지급 손금은 항상 경과이자 결산계상이 가능" 오답 — 특수관계인 + 1년 초과 거래는 경과이자 계상 특례 배제
"시용판매는 인도한 날이 귀속시기" 오답 — 구입 의사 표시일 (특약 있으면 거절기간 만료일)
