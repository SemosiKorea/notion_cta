1. 부당행위계산의 부인 (§41 / 시행령 §98)

1-1. 의의 및 적용 요건

💡 쉬운 비유: 가족·특수관계인과 세금 줄이기 위해 시가보다 싸게 팔거나 비싸게 사면, 세무서가 "시가대로 거래한 것처럼" 소득금액을 다시 계산합니다.
§41① 납세지 관할 세무서장 또는 지방국세청장은 배당소득(§17①8호)·사업소득·기타소득이 있는 거주자의 행위·계산이 그 거주자와 특수관계인과의 거래로 인하여 조세 부담을 부당하게 감소시킨 것으로 인정되는 경우
→ 그 행위·계산과 관계없이 해당 과세기간의 소득금액 재계산 가능
적용 여부소득 종류이유
✓ 적용§17①8호 출자공동사업자 배당소득손익분배비율 조작 가능
✓ 적용사업소득필요경비 크기 조작 가능
✓ 적용기타소득필요경비 인정, 조작 가능
✗ 제외근로소득필요경비 입증 요구 없음
✗ 제외연금소득필요경비 입증 요구 없음
✗ 제외이자소득·일반 배당소득필요경비 개념 없음
✗ 제외퇴직소득세법에 따라 과세표준 계산
✓ §101 별도양도소득§101에 별도 규정 (§41 비적용)
🚨 2025년 56번 ①번 — 옳지 않은 것!
"부당행위계산 부인 대상: 출자공동사업자 배당소득·사업소득·기타소득·양도소득"
→ 양도소득은 §41 아닌 §101에 별도 규정
🚨 2021년 52번 ②번 — 옳지 않은 것!
"배당소득과 이자소득 전체는 부당행위 대상이 아니다"
→ §17①8호(출자공동사업자) 배당소득은 §41 적용 대상. "전체가 아니다"는 오답!

1-2. 부당행위 사유 5가지 (시행령 §98②) 5%·3억 기준 주의

⚠ 1·2·3·5호: 시가와 차액이 3억원 이상이거나 시가의 5% 이상인 경우만 적용 / 4호는 기준 없음
1호 — 저가 양도·고가 매입
특수관계인으로부터 시가보다 높은 가격으로 자산 매입
특수관계인에게 시가보다 낮은 가격으로 자산 양도
5%·3억 기준 적용
2호 — 무상·저율 대부·제공
특수관계인에게 금전·자산·용역을 무상 또는 낮은 이율로 대부·제공
✅ 제외 (단서): 직계존비속에게 주택 무상 사용 + 직계존비속이 실제 거주하는 경우
(2021년 52번 ④번 옳은 것)
5%·3억 기준 적용
3호 — 고율 차용·제공받음
특수관계인으로부터 금전·자산·용역을 높은 이율로 차용하거나 제공받는 경우
5%·3억 기준 적용 / 이자 과다 필요경비 → 조세 감소
4호 — 무수익자산 매입
특수관계인으로부터 무수익자산을 매입하여 그 자산의 비용을 부담
5%·3억 기준 적용 안 됨
5호 — 기타 부당행위
총수입금액 또는 필요경비 계산 시 조세 부담을 부당하게 감소시킨 것으로 인정되는 경우
5%·3억 기준 (1~3호 준하는 행위만) / 포괄 조항

1-3. 주요 사례 분석 (2021년 52번 기출 직접 반영)

사례부당행위?근거
사업자가 여유자금을 부친에게 무상 대여해당 없음부친에게 사업자가 손해 → 조세 감소 없음 (52번 ⑤번 전단)
부친으로부터 시가 2배 이율로 차입 → 이자 필요경비 산입해당 있음 (3호)고율 차용 → 필요경비 과다 → 조세 감소 (52번 ⑤번 후단)
직계존비속에게 주택 무상 사용 + 실제 거주해당 없음 (2호단서)시행령 §98②2호단서 (52번 ④번 옳은 것)
근로소득자가 특수관계인과 저가 거래§41 해당 없음근로소득은 §41 적용 제외 (52번 ①번)

1-4. 양도소득 부당행위계산 (§101) — §41과 구별

§101② — 증여 후 10년 내 재양도 특수관계인(배우자·직계존비속 §97의2 이월과세 적용자 제외)에게 자산 증여 후
수증자가 증여일부터 10년 이내에 타인에게 재양도한 경우로서
수증자 세액(증여세+양도세) < 증여자 직접 양도세액
→ 증여자가 직접 양도한 것으로 봄 / 당초 증여세 부과 안 함 (§101③)
⚠ §101② 취득가액 = 증여자의 당초 취득가액 (증여 시 시가 아님)
단, 양도소득이 수증자에게 실질 귀속된 경우 → 적용 제외 (§101②단서)
2. 공동사업의 소득금액 계산 특례 (§43 / 시행령 §100)

2-1. 원칙 — 1거주자 계산 후 분배 (§43①②)

💡 쉬운 비유: 둘이 함께 운영하는 가게는 전체를 1거주자로 보고 소득 계산 후 지분에 따라 나눠 각자 신고합니다.
단계내용근거
Step 1: 1거주자 계산공동사업장을 1거주자로 보아 공동사업장별로 소득금액 계산§43①
Step 2: 분배약정된 손익분배비율에 따라 분배 (약정 없으면 지분비율)§43②
Step 3: 각자 신고분배받은 소득금액을 각자의 종합소득에 합산
🚨 공동사업 소득 = 사업소득만!
§43①: "사업소득이 발생하는 사업을 공동으로 경영"
→ 공동사업장에서 이자·배당소득이 발생해도 합산과세 대상 아님 (2025년 56번 ②번 정답)

2-2. 출자공동사업자 (시행령 §100①)

시행령 §100① 다음에 해당하지 않는 자로서 공동사업 경영에 참여하지 않고 출자만 하는 자:
1호. 공동사업에 성명·상호를 사용하게 한 자
2호. 채무에 대해 무한책임을 부담하기로 약정한 자
구분소득 분류수입시기Gross-up
출자공동사업자 분배소득배당소득 (§17①8호)과세기간 종료일 (12.31)적용 제외
일반 공동사업자 분배소득사업소득권리의무확정주의해당 없음

2-3. 특례 — 합산과세 (§43③ / 시행령 §100②④)

§43③ 거주자 1인 + 그의 특수관계인(시행령 §100②: 생계를 같이 하는 자)이 공동사업자에 포함 + 합산과세 사유 해당
→ 특수관계인의 소득금액을 주된 공동사업자(손익분배비율이 큰 자)의 소득금액으로 봄
거주자 1인 + 특수관계인이 공동사업자에 포함

▶ 합산과세 사유 2가지 (시행령 §100④)

호사유
1호신고서에 기재한 사업 종류·소득금액·지분비율·손익분배비율·관계 등이 사실과 현저하게 다른 경우
2호경영참가·거래관계·손익분배비율·재무상태 등으로 보아 조세 회피를 위해 공동으로 사업을 경영하는 것이 확인되는 경우
✅ 연대납세의무 (§2의2①단서):
합산과세되는 소득금액에 대해 특수관계인은 손익분배비율에 해당하는 소득금액에 대한 소득세를 한도로 주된 공동사업자와 연대납세의무 (2025년 56번 ③번 정답)

3-2. 예외 — 부동산임대업 결손금 (§45②)

🚨 다음 부동산임대업 결손금은 종합소득 과세표준 계산 시 공제 불가:
1호. 부동산 또는 부동산상의 권리를 대여하는 사업
2호. 공장재단·광업재단을 대여하는 사업
3호. 채굴에 관한 권리를 대여하는 사업 (대통령령)
✅ 단서 예외 (§45②단서): 주거용 건물 임대업은 §45① 일반 결손금 공제 적용!
구분당기 결손금 처리
일반 사업소득 결손금근로→연금→기타→이자→배당 공제 가능 (부동산임대업 소득에서도 공제 가능)
부동산임대업(비주거) 결손금다른 소득 공제 불가 → 이월결손금으로만 처리
주거용 건물 임대업 결손금§45①단서: 일반 공제 가능
⚠ 2021년 51번 ②번 오답: "주거용 건물임대업 포함 부동산임대업 결손금 공제 불가"
→ 주거용 건물 임대업은 공제 가능 (§45②단서)
⚠ 2021년 51번 ③번 오답: "일반 결손금은 부동산임대업 소득에서 공제 불가"
→ 일반 사업소득 결손금은 부동산임대업 소득에서도 공제 가능 (§45①)

3-3. 이월결손금 공제 (§45③)

§45③ 이월결손금 = 부동산임대업 결손금 + §45①②단서에 따라 공제하고 남은 결손금
→ 발생 과세기간 종료일부터 15년 이내에 끝나는 과세기간의 소득금액에서 공제
→ 먼저 발생한 과세기간의 이월결손금부터 순서대로 공제
이월결손금 유형공제 대상 소득
일반 사업소득 이월결손금 (§45③1호)사업소득금액 → 근로 → 연금 → 기타 → 이자 → 배당 순
부동산임대업 이월결손금 (§45③2호)부동산임대업 소득금액에서만 공제
⚠ 제척기간 도과 후 확인된 이월결손금 (§45③단서): 공제 불가
⚠ 2025년 56번 ④번 정답: "주거용 건물임대업을 포함한 부동산임대업에서 발생한 이월결손금은 소급공제가 적용되지 아니한다" → 옳은 것 (이월결손금 소급공제는 중소기업 사업소득에만 적용)

3-4. 기타 규정 (§45④⑤⑥)

조항내용
§45⑥ — 당기 결손금 먼저해당 과세기간에 결손금 발생 + 이월결손금 있으면 → 당기 결손금을 먼저 공제
→ 2021년 51번 ⑤번 오답: "이월결손금 먼저"는 틀림!
§45④ — 추계신고 이월결손금 불가추계신고·추계조사결정 시 이월결손금 공제 불가
단서: 천재지변·불가항력 장부 멸실 → 공제 가능
→ 2021년 51번 ④번 정답
§45⑤ — 금융소득 비교과세§62 비교과세 시 원천징수세율 적용 부분 → 공제 대상 제외
기본세율 적용 부분 → 사업자가 공제 여부·금액 결정 가능

4. 기타의 소득금액계산 특례 (§44·§46·§46의2)

4-1. 채권 등에 대한 소득금액 계산 특례 (§46)

💡 쉬운 비유: 채권을 사고팔 때 이자는 내가 보유한 기간만큼만 내 소득. A가 6개월·B가 6개월 보유했으면 각자 6개월치 이자만 신고.
§46① 대상: §16①1·2·5·6호의 채권·증권과 양도 가능한 증권(대통령령)
발행법인으로부터 이자를 지급받거나 채권을 매도하는 경우
→ 거주자에게 보유기간별로 귀속되는 이자 상당액을 이자소득으로 계산
구분소득금액 계산근거
보유기간 입증 가능보유기간별로 귀속되는 이자 상당액을 이자소득으로 계산§46①
보유기간 입증 불가§133의2①에 따른 원천징수기간의 이자 상당액이 해당 거주자에게 귀속§46②

📐 채권 보유기간 이자소득 계산

상황甲: 1.1 취득 → 6.30 乙에게 매도 / 연이자율 4%, 액면 1억원
甲1.1~6.30 (181일) 보유기간 이자소득= 1억 × 4% × (181/365) ≈ 1,983,562원 / 수입시기: 매도일 (령§45 10호)
乙7.1~12.31 (184일) 보유기간 이자소득= 1억 × 4% × (184/365) ≈ 2,016,438원 / 수입시기: 이자 지급일
각자 보유기간에 귀속되는 이자 상당액만 이자소득으로 신고

4-2. 상속의 경우 소득금액 구분 계산 (§44)

§44① 피상속인의 소득금액에 대한 소득세(상속인에게 과세할 것)와 상속인의 소득금액에 대한 소득세 → 구분하여 계산 (합산 금지)
§44② — 예외: 배우자 연금계좌 승계 가입자 사망 + 배우자가 연금외수령 없이 해당 연금계좌를 상속 승계하는 경우
→ 피상속인 소득금액을 상속인 소득금액으로 보아 소득세 계산
✅ 2025년 56번 ⑤번 — 옳은 것: "피상속인의 소득금액에 대한 소득세와 상속인의 소득금액에 대한 소득세는 구분하여 계산하여야 한다" → §44① 정확히 반영

4-3. 중도 해지로 인한 이자소득금액 계산 특례 (§46의2)

💡 쉬운 비유: 1년짜리 예금에서 이미 이자소득세를 냈는데 6개월 후 해지해서 이자가 줄었다면, 줄어든 이자를 당해연도 이자소득에서 빼줍니다.
§46의2 종합소득과세표준 확정신고 후 예금·신탁계약의 중도 해지로
이미 지난 과세기간의 이자소득금액이 감액된 경우
→ 중도 해지일이 속하는 과세기간의 이자소득금액에서 감액된 금액을 뺄 수 있다
단서: 경정청구를 한 경우 → §46의2 적용 불가 (중복 불가)
